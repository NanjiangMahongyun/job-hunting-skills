# 求职技能包 job-hunting-skills

一个普通求职者整理的求职方法库：**14 份知识库（判断依据）+ 12 个 Agent skill（处理工具）**，把「搜岗位 → 查公司 → 攒筹码 → 谈薪 → 审合同 → 离职维权 → 在岗与下一次跳槽」跑成可复用的流程。

目的只有一个：在信息不对称里**不被压价、不被坑、依法拿到自己应得的东西，也不去占别人便宜**。

> ⚠️ 全部内容不构成法律意见，具体争议以官方答复（12333 人社 / 12348 法律援助 / 12366 税务 / 12329 公积金）或执业律师意见为准。文中公司与人名均为虚构示例。

---

## 30 秒上手

1. 把整个仓库放进你的工作区。支持 `.claude/skills/` 的 Agent（Claude Code、Qoder 等）会自动识别这 12 个 skill；用其他模型也可以，直接把某个 `SKILL.md` 粘进对话即可。
2. 用大白话说你的处境，例如「帮我在南京找 AI 方向的岗位」「这家公司能不能去」「手上这个 offer 怎么谈」，Agent 会按 skill 的 `description` 命中对应流程。
3. 每个 skill 的第 0 步都会先问你 **🎓 学生/应届生 还是 💼 社会人员**——两条路的检索项、定价锚、合同重点完全不同，这一步别跳过。
4. 想看全局：用浏览器打开 [技能流程总览.html](技能流程总览.html)；想看细节与阅读顺序：[README-使用索引.md](README-使用索引.md)。

不想装 Agent、只想自己看书？跳过上面三步，直接看下面「[也可以完全不跑 skill](#也可以完全不跑-skill这几份是当教材写的)」那一节。

## 按你的处境找入口

| 你在哪一步 | 用哪个 skill | 它会给你什么 |
|---|---|---|
| 不知道该投什么 | `job-recommender` | 达标池 + 备选池，目标 30 个；搜不够就如实标缺口，不放宽你的硬条件 |
| 有目标公司，怕踩坑 | `company-due-diligence` | 风险评级，并把数据分成"能当事实"和"只能当线索"两级 |
| 手上有 offer 要谈 | `job-negotiation-strategist` → `salary-negotiation` | 先算你的筹码与对方弱点，再拆薪酬包、给话术、校验口径 |
| 拿到合同 / 三方协议 | `contract-reviewer` | 逐条对照知识库，标出风险条款与可直接开口的改法 |
| 正在离职或被裁 | `severance-calculator` | N / N+1 / 2N 怎么算、差额怎么主张、维权步骤 |
| 已入职，想稳住或准备跳 | `onjob-management`、`job-switch-decision` | 在岗留痕与风险监测；该不该跳、什么时候跳的判据 |
| 想先补认知再动手 | `knowledge-base/AI辅助求职实操教程.md` | 整条路径的全局认知，之后按需查对应资料 |

跨会话想让它记住你的情况，用 `memory-manager`——它会把档案与分析报告写到**本地 `memory/`**，这个目录不在本仓库里（见下方隐私说明）。

## 几点你该知道的

- **不含任何个人信息**：真实档案、真实公司分析、逐份 offer 报告只存本地 `memory/`，已被 `.gitignore` 忽略；公开版示例统一用 XX 公司、张三。
- **政策数字会过期**：所有数字与条号标注「机构 + 日期 + URL」，核实不到的写「未查到」，而不是留一个看起来精确的旧数字。司法解释以现行文本为准，引用前请复核一次。
- **不教造假**：判据是"当着对方的面把这条做法说出来，你还愿不愿意承认"。涉及取证的建议，同段写明合法边界（只录本人参与的对话，不窃听、不诱导、不剪辑）。
- **失实请开 issue**：说明依据，核实后一律更正或删除，不争论、不拖延。
- **借鉴来源**：skill 结构与 JD/谈薪框架参考了 [github/awesome-copilot → technical-job-search](https://github.com/github/awesome-copilot/blob/main/skills/technical-job-search/SKILL.md)（MIT），逐条链接见 [README-使用索引.md](README-使用索引.md)「借鉴来源与致谢」。
- **许可**：本仓库的知识库文档与 skill 说明一并按 [MIT 许可](LICENSE) 提供——可自由使用、修改、商用、再分发，保留版权声明即可，内容不作任何担保。
