# 自身优势与公司劣势通用框架（知识库）

> 适用：所有求职者，谈薪前对照着找自己的筹码  
> 原则：先知道"一般人有哪些优势、公司有哪些劣势"，再对照自己的具体情况筛选  
> 配套：找到通用筹码后，用 `.claude/skills/job-negotiation-strategist/SKILL.md` 结合你的简历和目标公司做定制化匹配

---

## 一、求职者的通用优势（大部分人至少占3-5条）

### 1.1 身份类优势

| 优势           | 为什么是筹码                                                                     | 怎么用                                      |
| ------------ | -------------------------------------------------------------------------- | ---------------------------------------- |

| **可立即到岗**    | 公司急着用人时，能立刻到岗 = 节省招聘时间成本                                                   | "我可以下周就到岗，不需要等毕业/交接"                     |
| **可提前实习**    | 还没毕业就能去实习 = 提前上手，毕业直接转正                                                    | "我可以提前来实习，熟悉业务后毕业直接转正"                   |

## 二、公司的通用劣势（大部分公司至少占2-3条）

### 2.1 经营压力类（公司急着用人的信号）

| 劣势             | 怎么判断                      | 对你意味着什么            |
| -------------- | ------------------------- | ------------------ |
| **HC快到期**      | Q4（11-12月）招聘、催你尽快答复       | 招聘负责人KPI压力大，愿意加价留人 |
| **项目急缺人**      | 面试节奏快、一周多轮、主动问到岗时间        | 你能立刻到岗 = 大筹码       |
| **核心人员刚离职**    | 岗位是"替补离职"而非"新增编制"         | 急着补位，议价空间大         |
| **招聘季尾声**      | 11月底-12月（秋招尾声）、4-5月（春招尾声） | 优质候选人少了，你更稀缺       |
| **候选人放鸽子后**    | 已发offer被拒，重新招人            | 重新走流程成本高，最愿意加价     |
| **成立时间短/融资靠后** | 成立1-2年、B轮以后烧钱期            | 急需出成果，对能干活的人愿意给钱   |

### 2.2 人才吸引力劣势（公司不好招人）

| 劣势             | 怎么判断             | 对你意味着什么               |
| -------------- | ---------------- | --------------------- |
| **脉脉/职友集负面评价多** | 搜"公司名+避雷/加班/拖欠"  | 候选人不愿意来，你愿意来 = 有筹码    |
| **地理位置偏**      | 郊区、通勤1小时以上、周边配套差 | 很多人嫌远不来，竞争小           |
| **薪资行业偏低**     | JD薪资低于市场中位数      | 他们知道自己薪资没竞争力，可能在其他方面补 |
| **公司知名度低**     | 没听过、官网简陋、无融资报道   | 候选人不愿意来，你愿意来 = 有筹码    |
| **技术栈老旧**      | 用SSH、jQuery等老技术  | 有经验的人不愿意来，新人反而有机会     |
| **加班严重/大小周**   | 脉脉评价、JD写"抗压能力强"  | 很多人接受不了，竞争小，但要算时薪     |
| **外包/驻场**      | JD出现"驻场""外派""甲方" | 很多人不愿意做外包，竞争小         |

### 2.3 制度性劣势（可以转化为谈判筹码）

| 劣势               | 怎么判断             | 谈判策略               |
| ---------------- | ---------------- | ------------------ |
| **社保按最低基数交**     | 面试时问"社保缴纳基数是多少"  | 隐性降薪，要求更高底薪补偿      |
| **公积金比例低（5%）**   | 问"公积金比例是多少"      | 要求提高比例或补贴补偿        |
| **年终奖不写进offer**  | HR只口头说"一般发X个月"   | 要求提高底薪或签字费替代不确定的年终 |
| **试用期长/打折多**     | 6个月试用期打8折        | 要求缩短到3个月或试用期全额     |
| **无加班费/大小周**     | 问"加班怎么算""有没有加班费" | 要求签字费或更高底薪补偿工作时长   |
| **补贴是"福利可随时取消"** | 合同写"公司福利可调整"     | 要求固定补贴写进offer      |
| **绩效占比过高**       | 底薪低、绩效占40%以上     | 要求提高固定底薪占比         |

### 2.4 岗位特定压力

| 劣势            | 怎么判断              | 对你意味着什么            |
| ------------- | ----------------- | ------------------ |
| **岗位挂了很久**    | 同一岗位招聘超过1个月       | 一直招不到人 = 急缺        |
| **JD要求高但薪资低** | 要求3年经验但给应届生价      | 招不到有经验的，你愿意来 = 有筹码 |
| **团队人少**      | 面试时问"团队多少人"，答3-5人 | 一个人当两个人用，你的价值大     |
| **新业务/新部门**   | 刚成立的团队、新产品线       | 不确定性高，很多人不敢来，竞争小   |

## 四、使用方法

### 第一步：找自己的优势

对照第一部分，把你符合的优势全部列出来（至少3-5条），每条都要有**具体证据**（不是"我学习能力强"，而是"我一周上手了X技术"）。

### 第二步：找公司的劣势

对照第二部分，通过尽调（company-due-diligence）和面试反问，把目标公司的劣势列出来（至少2-3条）。

### 第三步：匹配

用第三部分的速查表，把你的优势和公司的劣势一一对应，找出最硬的2-3个筹码。

### 第四步：定制化

用 `.claude/skills/job-negotiation-strategist/SKILL.md`，输入你的简历和公司尽调结果，生成针对这家公司的定制化话术和策略。

---

## 五、注意事项

1. **优势要有证据**：空口说"我学习能力强"没用，必须有具体事例支撑
2. **劣势要查证**：不要凭感觉说"这家公司加班多"，要通过脉脉/职友集/面试反问确认
3. **筹码要排序**：硬筹码（急缺人、稀缺技能）优先用，软筹码（稳定性、沟通好）辅助用
4. **不要一次全打出**：谈判是回合制，先出一个筹码，看对方反应，再出下一个
5. **底线要清楚**：知道自己最低能接受什么，低于底线就走，不要为了拿offer无底线让步
