## 六、离职/被辞退

| 问题           | 查哪里       | 关键点                              |
| ------------ | --------- | -------------------------------- |
| N/N+1/2N怎么算  | 第六部分第三十五节 | N=工作年限×月工资，+1仅限第40条未提前通知，2N=违法解除 |
| 工作不满1年怎么算    | 第六部分第三十六节 | 6个月以上按1年算，不满6个月算0.5个月            |
| 被劝退写不写辞职信    | 第六部分第三十七节 | 绝不写，主动辞职=0补偿，要书面解除通知             |

| 主动辞职能拿补偿吗    | 第六部分第三十七节 | 只有"被迫解除"可以（欠薪/未缴社保等），先发通知再走人     |
