# 第一部分 求职前：身份、材料与政策底牌

## 一、应届生身份——你最值钱也最容易搞丢的东西

**依据**：《中央机关及其直属机构考试录用公务员报考指南》；人社部发〔2024〕44 号；国家大学生就业服务平台政策解读（中国政府网 2024-06；国家大学生就业服务平台 2025-07）。

**定义**：国家统一招生的普通高校毕业生，离校时及在**择业期（国家规定 2 年）**&#x5185;未落实工作单位，其户口、档案、组织关系仍保留在原毕业学校或各级毕业生就业主管部门、人才交流服务机构、公共就业服务机构的，可按应届高校毕业生对待。

**什么情况会让你丢掉应届生身份**

| 行为                | 是否影响        | 说明             |
| ----------------- | ----------- | -------------- |
| 在校实习              | ❌ 不影响       | 不建立劳动关系        |
| 只签三方协议、未签劳动合同未缴社保 | ❌ 一般不影响     | 实践共识，非全国统一明文规定 |
| **签劳动合同 + 缴社保**   | ✅ **大概率失去** | 多数地区以社保记录为判定依据 |
| 已办理就业登记           | ✅ 可能失去      | 以当地认定为准        |

**这个身份值多少钱**：考公考编大量岗位限"应届"；国企、银行校招主要面向应届生；南京等地人才补贴（生活补贴、租房补贴、面试补贴）普遍要求应届生身份。**所以：如果你还在考公考编，签劳动合同前一定先算清楚这笔账。**

> ⚠️ **地方差异**：2025 年起北京、湖北、四川、新疆等地放宽认定，取消社保缴纳限制、延长至毕业后 2–3 年。江苏省 / 南京市目前仍以"2 年内未就业 + 档案保留"为核心标准，**具体以招聘单位公告为准**。（新京报 2025-11）

## 二、三方协议（就业协议书）

**法律性质**：属于**民事预约合同**，适用《民法典》合同编，**不适用《劳动合同法》**。你到单位报到并签订劳动合同后，三方协议自行终止。

- **违约金**：法律**无统一上限**。教育部 2019 年建议一般不超过 5000 元，多数高校审核时参照执行。调整依据是《民法典》第五百八十五条第二款：约定的违约金**过分高于**造成的损失的，法院或仲裁机构可根据**当事人的请求**予以适当减少（低于损失的则可请求增加）——**法院不主动调整，要你自己在仲裁／诉讼中提出**。现行司法解释（《民法典》合同编通则解释，法释〔2023〕13 号，2023-12-05 施行）**第六十五条**：约定违约金超过造成损失的 **30%** 的，法院**一般可以**认定为"过分高于"；**恶意违约的一方请求减少违约金，法院一般不予支持**。⚠️ 原《合同法解释（二）》第二十九条已于 2021-01-01 废止，不要再引用它。**考上研究生、应征入伍、单位倒闭注销等属法定免责情形**。（法制日报 2024-05；中国新闻周刊 2026-08；最高人民法院 2023-12-04）
- **企业违约怎么办**：可能构成缔约过失责任，可主张信赖利益损失（招聘成本、错过就业黄金期）。协议约定了企业违约金的按约定执行；未约定或显失公平的，法院可酌定赔偿。
- **解约流程**：书面通知对方 → 协商一致 → 取得**解约函** → 向学校申请换发新协议。**务必保留 EMS 单号 / 邮件发送记录**，别只打电话。
- **网签三方**：教育部已推广"全国高校毕业生网上签约与毕业去向登记平台"，电子签名与纸质具有同等法律效力（《电子签名法》第 14 条）。

## 三、报到证已取消，但档案更要小心

**自 2023 年起不再发放就业报到证**，取消补办、改派手续，不再作为招聘录用、落户、档案转递的必需材料。（人社部发〔2023〕26 号，中国政府网 2023-05）

**档案转递规则**（人社厅发〔2023〕20 号）

- 到机关 / 国企 / 事业单位 → 转至就业单位
- 到非公单位 / 灵活就业 → 转至**就业地或户籍地**公共就业人才服务机构
- 未就业 → 可转户籍地人才服务机构，或在原校保留 2 年

> 🚨 **档案绝对不能自己拿在手里，更不能私自拆封。** 必须"公对公"通过机要通信或 EMS 标准快递转递。
>
> **"死档"后果**：影响考公政审、职称评审、退休工龄核定。  
> **补救**：联系户籍地人才服务机构或原毕业院校，提交身份证、档案情况说明等材料，经审核确认材料完整后重新封存托管；已拆封的需逐份核验材料真实性。

## 四、南京落户与人才补贴（这是你该领的钱）

**落户依据**：《南京市人才落户实施办法》，**2026 年 1 月 10 日起执行**，有效期 3 年。（南京市公安局 2025-12；南京市人民政府 2026-01）

| 学历                                | 条件             |
| --------------------------------- | -------------- |
| 研究生及以上 / 45 周岁以下本科（含非全日制研究生、留学归国） | **无社保要求**，直接申请 |
| 35 周岁以下大专                         | 正在缴纳南京城镇职工社保即可 |
| 35–40 周岁大专                        | 连续缴纳南京社保满 6 个月 |

- **暂不落户**：可申领江苏省居住证（拟在宁居住 6 个月以上即可申请）。
- **集体户口利弊**：好处是无需购房即可落户南京；坏处是子女入学、房产交易受限，后续购房或迁入配偶户时需迁出。

**南京人才补贴**（《紫金山英才计划宁聚项目实施细则》，南京市人社局 2026-03）

| 项目         | 学士        | 硕士    | 博士     |
| ---------- | --------- | ----- | ------ |
| 一次性生活补贴    | **1 万元**  | 3 万元  | 10 万元  |
| 住房租赁补贴（每月） | **600 元** | 800 元 | 2000 元 |

> 💡 **补贴期限累计不超过 36 个月**（实际租金低于补贴标准的按实际租金补贴）。2026-03 优化通知已扩大专科覆盖：具有**高级工及以上**职业资格证书/职业技能等级证书的大专学历全日制毕业生，住房租赁补贴 **500 元/月**，其中在宁人工智能（软件）、机器人等重点产业另有标准——以南京市人社局十部门《关于进一步优化高校毕业生…通知》（2026-07）细则为准。
>
> 💡 **申领时间**：符合条件的新增人员连续参保首月自 2026-01-01 起算，最早可于 2026-07-01 申领；同一人只能享受一次生活补贴。
>
> 这笔钱很多应届生不知道，**入职缴社保后主动去南京市政务服务网 / 江苏智慧人社查申领入口**，别让公司代办，也别错过时限。
>
> 来源：南京市人社局《南京市高校毕业生生活补贴操作办法》政策解读（2026-03-04，rsj.nanjing.gov.cn）；南京市人力资源和社会保障局等十部门进一步优化高校毕业生住房租赁补贴通知（2026-07-02，nanjing.gov.cn）。政策有时效，申领前复核一次。

## 五、党团关系与学历认证

- **党组织关系**：已就业转至用人单位党组织；未就业转户籍地街道 / 社区党组织或人才服务中心流动党员党支部。介绍信有效期一般 30–90 天，**逾期需重开**。
- **团组织关系**：通过"智慧团建"系统线上转接。
- **学历认证**：学信网（chsi.com.cn）下载《教育部学历证书电子注册备案表》；学位网（cdgdc.edu.cn）申请《中国高等教育学位在线验证报告》。**落户、入职都要用，提前下载存好。**

## 六、实习 vs 试用期——别被混着说

| 对比项  | 在校实习                               | 毕业后试用期                     |
| ---- | ---------------------------------- | -------------------------- |
| 法律关系 | 民事关系，**不建立劳动关系**                   | 劳动关系，受《劳动合同法》保护            |
| 社保   | 无法定缴纳义务（建议买意外险）                    | **必须缴纳五险一金**               |
| 协议类型 | 实习协议                               | 劳动合同（含试用期条款）               |
| 报酬底线 | 不低于当地非全日制小时最低工资（江苏一类地区 **25 元/时**） | 不低于合同约定工资 **80%** 且 ≥ 最低工资 |

- **实习协议必看**：实习报酬、工作时间、意外伤害保险、保密义务、知识产权归属。
- 🚨 **"实习转正"的口头承诺不构成法律约束。** 必须要求书面约定转正条件与时间节点，否则你就是廉价劳动力。
- **顶岗实习维权**：未取得毕业证前仍属实习关系，但若实际工作内容、管理与正式员工无异，部分地区司法实践可能认定存在**事实劳动关系**。保留考勤记录、工作沟通截图。

# 第二部分 找工作：投递、面试、避坑

## 七、简历与投递

**信息泄露风险**：海投时简历含身份证号、手机号，极易被倒卖。  
✅ **投递版本隐去身份证号**，只留必要联系方式；优先用招聘平台在线简历而非附件。

**简历"美化"与"造假"的边界**

| ✅ 可以包装                             | ❌ 绝对不能编                |
| ---------------------------------- | ---------------------- |
| 量化成果（"提升效率"→"将构建时间从 20 分钟降到 5 分钟"） | 虚构公司、岗位、职级             |
| 突出个人在团队项目中的贡献                      | 伪造学历学位                 |
| 调整表述顺序，把强项放前面                      | 捏造不存在的项目经历、把别人做的写成自己做的 |
| 技术栈按熟练度排序                          | 伪造薪资流水、伪造 offer        |

> 背调会逐一核实。**造假被发现直接取消录用，且可能进入行业黑名单。** 真有出入的地方，在背调前主动向新公司说明，远好于被查出来。

## 八、面试前：先查公司（你在背调它）

**必查四件事**

1. **工商登记状态**：是否存续、有无经营异常 → 国家企业信用信息公示系统 gsxt.gov.cn
2. **司法诉讼记录**：劳动争议案件量、是否批量欠薪 → 企查查 / 天眼查 / 中国裁判文书网
3. **招聘历史**：同一岗位常年挂着 = 高流失率或只是 KPI 面
4. **员工评价**：脉脉 / 知乎 / 小红书 / 职友集，搜"**公司名 + 避雷**""公司名 + 加班"

**红旗信号**：成立不足 1 年且无融资；社保参保人数 <10 人却声称百人团队；大量劳动仲裁记录；多个关联公司频繁注销新设；JD 薪资区间异常宽泛（如 5K–20K）。

**识别 KPI 面 / 免费方案面**：面试官全程不问你的经历，只让你"做个方案试试"；面试时长极短且不做记录；要求提交完整策划案 / 可运行代码 / 设计稿作为"测试题"。  
✅ **可以给思路框架，拒绝交付完整可用成果。** 话术："这部分涉及具体实现，我更愿意在入职后结合真实业务场景完成，现场可以先聊我的技术方案和取舍思路。"

## 九、面试中：反问清单与红旗信号

**反问面试官（选 3–4 个，这些问题本身就是筛选器）**

| 问题                        | 你在判断什么                 |
| ------------------------- | ---------------------- |
| "这个岗位为什么招人？是新增编制还是替补离职？"  | 业务扩张 vs 人员流失           |
| "团队目前多少人？我直接汇报给谁？"        | 组织架构是否清晰               |
| "入职前 3 个月最需要我解决的核心问题是什么？" | 岗位需求是否真实明确             |
| "**加班和调休的实际执行情况是怎样的？**"   | 比直接问"加不加班"有效得多，能听到真实答案 |
| "试用期考核的具体标准和流程是什么？"       | 转正难度、是否会被"卡试用期"        |
| "过去一年团队晋升和调薪的比例大概是多少？"    | 发展空间是否真实存在             |

**红旗信号**：回避具体问题；回答前后矛盾；对团队规模含糊其辞；用"**我们这行都这样**"来合理化不合理制度；全程只谈情怀不谈钱和考核标准。

**技术岗专项注意**

- 被要求现场写**核心业务代码**：可展示算法思路，拒绝写出可直接商用的完整实现。
- 被索要**过往项目源码**：礼貌拒绝，说明涉及前雇主知识产权（这本身也是在考察你的职业操守）。
- 被问**薪资流水 / 身份证 / 银行卡号**：面试阶段无需提供，仅在正式入职、签了背调授权书后才配合。

**谈薪时机**：不要在业务面试环节主动报价。

> 话术："薪资方面，我希望在全面了解岗位职责和发展空间之后再沟通，相信公司会有合理的薪酬体系。"

## 十、招聘诈骗与灰色套路（应届生重灾区）

### 10.1 培训贷 / "招转培"——最狠的一种

**套路三步**：发布 AI / 编程 / 剪辑等热门岗位 → 面试时贬低你能力，称"需岗前培训才能上岗" → 诱导签培训协议 + 第三方分期贷款 → 培训质量差、承诺的岗位根本不存在 → 你背上上万元债务且征信受损。

**识别信号**

- 面试不谈业务，只反复强调"你能力不足"
- 要求签**两份文件**：培训协议 + 贷款合同
- 用"分期付款""入职后从工资扣""公司帮你还"淡化贷款性质
- 培训费过万且**指定**贷款平台

**应对**：当场拒绝签字，直接离开。  
**已经签了的补救**

- 依据《民法典》第 148 条（受欺诈方可请求撤销民事法律行为）诉请**撤销合同**
- 向 **12315** 投诉培训机构、向 **12378** 反映违规放贷
- 保留聊天记录、协议、转账凭证、录音（录音只录你本人参与的对话，不窃听他人、不诱导陈述、不剪辑拼接），形成完整证据链

> **法律依据**：《劳动合同法》第 9 条禁止用人单位以任何名义向劳动者收取财物；《民法典》第 148 条欺诈撤销。  
> **官方提示**：人社部等五部门 2026 年 5 月《警惕"招转培""培训贷"等风险提示》（chinajob.mohrss.gov.cn/c/2026-05-18/543038.shtml）；北京一中院 2026 年 8 月培训贷典型案例（bj1zy.bjcourt.gov.cn/article/detail/2026/08/id/9453479.shtml）；极目新闻 2025-12 报道多名毕业生被诱导背上 2 万余元贷款（ce.cn/xwzx/shgj/gdxw/202512/t20251224_2663649.shtml）。

### 10.2 各类收费——法律明令禁止

**名目**：报名费、体检费、押金、服装费、工牌费、"内推费"、"付费直签"、"交钱保过"。

**识别信号**：入职前要求转账至**个人账户**或非公司对公账户。

✅ **一律拒付。** 《劳动合同法》第 9 条明确：用人单位招用劳动者，**不得扣押居民身份证和其他证件，不得要求劳动者提供担保或者以其他名义向劳动者收取财物**。正规内推不收费；央企国企招聘只通过官网和校招渠道，**没有任何"内部名额"**。

> 五部门 2026 年 10 月专门发布《警惕"央国企内推"等骗局风险提示》（cpd.com.cn/shizheng/1026/t_1254299.html）；教育部 2024 年 4 月提醒警惕"付费内推"（moe.gov.cn）。

### 10.3 帮信罪——会坐牢的那种

**套路**：以"兼职""帮公司走账""代收代转""配合反诈测试"为名，诱使你出借银行卡、微信 / 支付宝账号，或参与跑分刷单。

**识别信号**："出租银行卡日赚 200–500""帮忙转个账就走个流水""你的卡借公司用一下"。

> 🚨 **2023 年帮信罪起诉 14.7 万人，25 岁以下占三分之一，已成为第三大罪名。** 这不是"最多罚点钱"，是刑事犯罪，会毁掉你考公、考编、进国企、政审的全部可能。

✅ **绝对不出借任何账号、任何证件。** 已经参与的**立即自首**——重庆江北检察院 2024 年案例中，主动自首的大四学生获**不起诉**决定。

> **法律依据**：《刑法》第 287 条之二帮助信息网络犯罪活动罪；"两高一部"2025 年 7 月《关于办理帮助信息网络犯罪活动等刑事案件有关问题的意见》（[www.court.gov.cn/zixun/xiangqing/472121.html](https://www.court.gov.cn/zixun/xiangqing/472121.html)）；人民日报 2025-08 以案说法（paper.people.com.cn/rmrb/pc/content/202508/31/content_30101247.html）。

### 10.4 冒名顶替与境外高薪

**套路**：伪造大厂 / 国企 offer、假 HR 工牌、假办公地点；或以"境外高薪 IT / 客服 / 翻译"招募，实为东南亚电诈园区。

**识别信号**

- 面试地点在**居民楼 / 酒店房间**而非公司办公区
- offer 无公司公章、薪资结构模糊、HR 只用私人微信沟通
- 境外岗位薪资远超行业均值，还"包机票包签证包住宿"

✅ **应对**：通过国家企业信用信息公示系统核验公司真伪；打公司官网公示电话反向确认是否有这次招聘；境外务工须查企业是否有**对外劳务合作经营资格**。

### 10.5 其他灰色岗位

- **传销型**：拉人头、发展下线、集中住宿、封闭培训、没收手机 → 立刻走
- **免费劳动力型**："先做个方案""测试题即真实业务需求" → 只给思路不给成品
- **模特 / 主播 / 陪聊 / "艺人助理"**：常伴随收费、陪酒、擦边内容要求

## 十一、背景调查

**什么时候做**：通常在发 offer 后、入职前；部分企业在终面前启动。**必须获得你的书面授权才能进行**——授权书上的范围要看清楚，超出范围的信息你有权拒绝。

**应届生被查什么**

1. 学历学位（学信网验证，**造不了假**）
2. 实习经历真实性（联系实习单位 HR / 直属上级核实岗位、时间、表现）
3. 在校表现（辅导员 / 导师访谈）
4. 有无犯罪记录、失信被执行记录
5. 有无商业利益冲突（在外开公司、持股）

**你要提前做的准备**：征得实习直属上级、导师或辅导员同意作为证明人，**提前告知对方可能接到背调电话**，确保评价内容与你简历一致。

**造假的后果**：轻则取消 offer；重则已入职后被解除劳动合同，且**不构成违法解除**，你拿不到任何补偿（《劳动合同法》第 39 条第 5 项：以欺诈手段订立合同）。

## 十二、入职体检与就业歧视——这两项法律站你这边

### 12.1 乙肝检测：法律明确禁止

《就业促进法》第 30 条：**"用人单位招用人员，不得以是传染病病原携带者为由拒绝录用。"**  
《就业服务与就业管理规定》进一步明确：除国家规定禁止乙肝携带者从事的特殊岗位外，**不得强行将乙肝病毒血清学指标作为体检标准**。违规者责令改正并可处 1000 元以下罚款，造成损害需赔偿。

> 特殊岗位例外仅限血站采血人员、特警、婴幼儿护理等极少数法定岗位。**软件开发 / 测试岗位不在限制范围内。**  
> 来源：《就业促进法》第 30 条（mohrss.gov.cn）；人社部发〔2010〕12 号、人社厅发〔2010〕22 号。

### 12.2 女性婚育询问：违法

《妇女权益保障法》（2023 年 1 月 1 日施行）**第 43 条**明确，用人单位在招录过程中**不得**：  
① 限定男性或男性优先；  
② **除个人基本信息外，进一步询问或调查女性求职者的婚育情况**；  
③ 将妊娠测试作为入职体检项目；  
④ 将限制结婚生育作为录用条件。

> **已有执法案例**：上海黄浦区人社局 2025-12 查处某公司在面试登记表中设置"是否怀孕"问询条目，责令整改（rsj.sh.gov.cn）；北京朝阳区人社局对要求女员工提供孕检证明的公司**罚款 2.2 万元**（legaldaily.com.cn 2026-08）。  
> 被问到"有没有男朋友""打算什么时候结婚生孩子"，你可以直接答："这个问题《妇女权益保障法》第 43 条规定招聘中不能询问，我们还是聊岗位吧。"

### 12.3 其他体检事项

- **体检费**：法律未明文规定谁出，实践中多数由企业支付，部分地区地方性法规明确要求企业承担。**入职前问清楚**；要你先垫付且金额不合理的，是风险信号。
- **体检不合格被拒**：你有权要求出具**书面理由**；认为构成歧视的，可向劳动监察投诉或提起就业歧视诉讼。
- **色觉 / 视力限制**：仅驾驶、精密仪器操作等特定岗位可设限，软件开发岗一般不设。

## 十三、Offer：口头的不算数

**必须拿到书面 offer**（邮件 offer 需由公司官方邮箱发出，最好有公章扫描件）。

**书面 offer 必须写明这 6 项**

1. **薪资结构**：基本工资 / 绩效 / 年终奖**分项列明**，不要只写"综合年薪"
2. 岗位名称
3. 工作地点（具体到楼栋）
4. 入职时间与报到材料
5. 试用期时长及试用期工资
6. 五险一金缴纳基数与比例

**多 offer 时怎么争取时间**：如实告知"还在等其他结果"，协商延长答复期限（通常可争取 3–7 天）。  
🚨 **不要同时接受多个 offer 再毁约**——三方协议违约要承担赔偿责任，行业圈子也小。

**判断自己是不是"备胎"**：超过承诺反馈日期未回复；HR 含糊说"还在审批中"；被要求"先等等看"。  
✅ **主动跟进一次**，仍无明确答复即视为备选，继续投递，不要停下等。

# 第三部分 谈薪：你的优势与对方的弱点 ★核心章节

## 十四、先搞清楚行情，再开口

**没有数据就没有谈判，只有乞讨。**

| 渠道              | 用法                         | 注意                    |
| --------------- | -------------------------- | --------------------- |
| **OfferShow**   | 搜公司 + 岗位，看白菜 / SP / SSP 档位 | 用户自报数据，**取中位数**参考     |
| **牛客网薪资爆料**     | 搜目标公司 + 年份 + 岗位            | 校招数据最全，看评论区交叉验证       |
| 脉脉职言            | 搜公司名 + 薪资 / 待遇             | 社招为主，应届数据偏少           |
| BOSS 直聘 / 拉勾 JD | 搜同类岗位薪资区间                  | **JD 区间普遍偏高，取下限到中位数** |
| 职友集            | 公司薪酬统计（⚠️ 看准网已于 2024-09-30 关停，不要再引用） | 样本量小时参考价值有限           |

**形成锚点的方法**：收集 **3–5 个数据点** → **中位数 = 你的目标价**，**下限 = 你的底线（低于这个数不去）**，**上限 = 谈判起点**。全部截图保存，谈判时心里有据。

## 十五、谈薪时机与话术

**最佳窗口**

- 终面通过后 HR 主动谈 offer 时
- 收到口头 offer 后、书面 offer 发出前（**这是最好的时机，改起来最容易**）
- 对方流露强烈录用意向时

**不要谈的时机**：初面、还没展示价值、HR 未明确录用意向时。

> 被过早追问的话术："在充分了解岗位职责之前，我更看重岗位匹配度，希望双方确认意向后再深入沟通薪酬。"

**网申表里的"期望薪资"怎么填**

- ❌ 不要填"面议"——HR 可能直接筛掉你
- ❌ 不要填死一个数字
- ✅ 填**合理区间**：下限 = 你的可接受底线，上限 = 理想目标，**跨度控制在 2–3K**

**第一次被问"期望薪资"——可直接照念的模板**

> "结合南京同岗位应届生的市场薪资行情，以及我在【XX 实习 / 项目】中积累的【具体技能 / 成果】，我的期望薪资区间是 8K–10K。我更看重岗位发展和团队氛围，也尊重公司的薪酬体系，愿意双向沟通。"

**核心原则**：报**区间**不报死数；用**市场行情 + 个人价值**做支撑；**绝不说**"我同学都拿多少""公司看着给就行"。

## 十六、你的筹码：应届生在谈判桌上真正有的优势

### 16.1 最硬的筹码——政府补贴让企业的实际用人成本远低于你的薪资数字

以下政策均已核实：

| **一次性扩岗补助**         | **1000 元/人**                                 | 招用 2026 届高校毕业生，足额缴失业 / 工伤 / 养老保险满 3 个月   | 江苏省人社厅等四部门通知 2026-08；南京市政府官网 2026-09     |
| **小微企业吸纳高校毕业生社保补贴** | 企业缴纳的社保费**全额**（不含个人部分），**最长 12 个月**          | 小微企业招用毕业年度及离校 2 年内未就业高校毕业生，签 1 年以上合同并缴社保 | 江苏省人社厅知识问答 2025-12；南京市就业补助资金管理办法 2025-10 |

> 💡 **谈判中怎么用**：当 HR 以"招你成本高"压价时，可以温和点一句——
> "我了解到南京和江苏对招用应届生有多项社保补贴和扩岗补助，企业的实际用人成本应该比我个人的薪资数字要低一些，这也让我更有信心为公司创造价值。"
> **点到为止，不要替 HR 算账、不要显得你在教他做事。** 这句话的作用是打破"你值这个价吗"的框架，把它换成"你其实很便宜"。

### 16.2 其他隐性筹码

- **可塑性强**：没有不良工作习惯，更容易融入团队文化和技术栈——用人部门喜欢你，比 HR 喜欢你更有用
- **校招 HC 是独立预算**：校招和社招通常分开核算，**不会挤占社招名额**，HR 说"没有预算"往往是不准确的
- **身份可用于企业申报**：高新技术企业评审、部分资质认定需要一定比例的应届 / 青年人才
- **无家庭负担**：客观上更能适应高强度节奏（但**不要主动承诺加班**，那是给自己挖坑）

## 十七、对方的弱点：招聘方的压力与破绽

### 17.1 他们什么时候最急

| 场景 | 为什么急 |
|---|---|
| **HC 到期 / 年底冲编制** | Q4 尤其 11–12 月，未用完的 HC 可能被收回，招聘负责人的 KPI 直接受影响 |
| **项目急缺人** | 新项目启动、核心人员突然离职后的补位期 |
| **招聘季末尾** | 秋招尾声（11 月底–12 月）、春招尾声（4–5 月），优质候选人已经签完了 |
| **候选人放鸽子后** | 已发 offer 被拒，重新走流程成本极高，这时他们最愿意加价 |

### 17.2 怎么判断对方是不是急（这些是送分信号）

- 面试节奏快，一周内安排多轮
- **催你尽快答复 offer**
- 多次加面，或主动追加面试轮次
- **主动问到岗时间**、能不能提前实习
- HR 语气从"考察你"变成"争取你"
- 薪资讨论中 HR **主动**提出上调或增加福利

### 17.3 HR 与用人部门的利益不一致——这是你可以用的裂缝

- **用人部门**：急着要人干活，倾向尽快发 offer，薪资可适当放宽
- **HR**：KPI 是招聘完成率 + 人力成本控制，**有动力压价，但同样有动力促成签约**（招不到人他也是没完成 KPI）

✅ **利用方式**：如果用人部门负责人对你评价很高，谈薪时可以自然引用——
> "面试时【X 总】提到我在【某技术方向】的经验正好是团队现在缺的，我也很认可这个方向。基于这一点，我想看看薪资上是否还有一些空间。"

这句话让 HR 意识到"这个人业务部门很想要，招不到是我的责任"。

### 17.4 反面提醒：这些做法会翻车

- ❌ **伪造 offer 抬价**：一旦被要求提供截图 / 原件立刻穿帮，行业圈子小，口碑永久受损
- ❌ **拖延太久**：超过约定答复期限不回复，offer 可能被撤回。可申请延长 3–5 天，**不要无限拖**
- ❌ **态度傲慢 / 威胁语气**："不加到 X 我就不来"——即使你真有更好的 offer，也用协商语气
- ❌ **频繁反复**：谈好又变卦，会被标记为"不稳定候选人"，HR 之间会互相通气

## 十八、谈判战术

### 18.1 三个核心工具

**① 锚定效应**
让对方先报价，然后围绕他的**上限**谈。如果你必须先报，报一个**略高于目标价**的数字作为锚点，并且给区间不给精确数。

**② BATNA（你的替代方案）**
**手握 2 个以上 offer 才有真正的议价权。** 只有一个 offer 时，你的谈判力接近于零——所以哪怕已经拿到心仪 offer，也继续投几家。
> 话术："我手上还有 XX 公司 X K 的 offer，但我更倾向咱们公司的【具体原因：技术栈 / 业务方向 / 团队】，想看看薪资上有没有空间。"
> **表达意愿 + 展示替代选项，不是威胁。**

**③ 多 offer 互相抬价**
先对 A 公司表达强烈意愿，再提 B 公司的更高报价，问"能否在这个基础上调整"。
- ✅ "我很想来 A，只是薪资差距让我有些犹豫，能不能帮我缩小这个差距？"
- ❌ "你不加我就去 B。"

### 18.2 底薪谈不动时，改谈这 9 项

| 项目 | 为什么好谈 / 说明 |
|---|---|
| **签字费 sign-on** | 一次性发放，不进入薪酬体系，**HR 审批权限通常更大**，最容易拿到 |
| 租房 / 餐补 / 交通补 | 另外记得自己申领南京住房租赁补贴（学士 600 元/月），这笔钱不占公司预算 |
| **绩效保底** | 争取前 3–6 个月绩效按全额发放，避免试用期被打折 |
| **调薪时间点写进 offer** | "入职满 6 个月进行首次调薪评估"**远比"以后会调"有约束力** |
| 职级 | 直接影响起薪和晋升速度，一定问清对应级别 |
| 试用期 | 争取缩短至 3 个月；试用期工资不低于转正工资 80%（法定下限） |
| 远程 / 弹性 | 对开发岗可行性较高，可作为补充条件 |
| 培训预算 / 考证报销 | 部分公司有专项经费 |
| **期权** | ⚠️ **对应届生基本没价值**：未上市公司行权价不明、退出路径不确定、离职即作废。不要被"估值 XX 亿"忽悠，**优先争取确定性收入** |

### 18.3 HR 压价话术反驳表（照念即可）

| HR 说 | 你答 |
|---|---|
| "你这个学校 / 经验给不了这么多" | "理解您的顾虑。不过我的【实习成果 / 项目数据】已经证明我能快速上手。相比培养成本，我更看重的是能为团队带来的产出。" |
| "我们预算有限" | "理解预算约束。**如果月薪空间有限，能否在签字费、住房补贴或绩效保底方面做一些倾斜？**" |
| "先入职后调薪" | "感谢您的信任。**能否把调薪时间和评估标准写进 offer？** 这样双方都有明确预期。" |
| "行业都这个价" | "我查了同岗位在南京的市场数据，中位数在 X–Y 之间。我的期望是基于调研和个人能力的合理范围。" |
| "你要求太高会显得不好合作" | "我的报价是基于市场调研的合理区间，我也表达了灵活沟通的意愿。我相信合理的薪酬匹配才能让双方长期合作。" |
| "这个薪资已经是我们能给应届生的最高档了" | "那我想了解一下这个档位对应的职级和考核标准是什么？如果我能达到更高一档的要求，能否按更高档执行并写进 offer？" |

（左列 HR 压价话术为常见谈薪场景归纳；右列应对话术为本包整理。**牛客 / 知乎 / 脉脉等 UGC 内容只能作为话术素材与线索，不能当作某家公司的薪酬事实**，定价请一律以可核实的官方薪酬调查与检索结果为准。）

### 18.4 谈薪红线

- ❌ **不要谎报当前薪资或已有 offer**——背调会核实流水和 offer 原件，造假直接取消录用
- ❌ **不要口头答应后反悔**——损害信誉；不确定就说"我需要 1–2 天综合考虑"
- ❌ **不要接受"薪资保密、合同不写金额"**——劳动合同**必须**写明劳动报酬，只靠口头约定违法
- ✅ **offer 必须书面盖章**，含薪资结构、入职时间、岗位、工作地点、试用期条款

## 十九、看懂薪资结构：别被"综合年薪"骗了

### 19.1 N 薪的区别

| 说法 | 真实含义 |
|---|---|
| **12 薪** | 纯月薪制，年终奖另算（可能是 0，也可能是 3 个月） |
| **13 薪** | 年底固定多发 1 个月，**确定性高** |
| **14–15 薪** | 通常含 1–3 个月年终奖，**要看是否"保底"** |

> 🚨 **写在合同里的才是确定的，"最高可达 15 薪"不等于保证。**
>
> **"年薪 15 万"的常见水分**：月薪 8K×12 = 9.6 万 + 绩效 2 万 + 补贴 1 万 + **公积金单位缴纳部分** 2.4 万 = 15 万。
> **务必拆开问清**：底薪多少？绩效占比多少、考核标准是什么？年终奖是否保底、什么时候发？五险一金缴费基数是多少、公积金比例几个点？

### 19.2 到手工资怎么算（2026 年南京口径）

**社保个人缴纳比例**（江苏省人社厅等四部门通知 2025-09 发布；南京市人民政府官网 2026-10 确认）

| 险种 | 个人比例 | 备注 |
|---|---|---|
| 养老保险 | **8%** | 计入个人账户 |
| 医疗保险（含生育） | **2%** | 生育保险已并入医保 |
| 失业保险 | **0.5%** | 阶段性费率延续 |
| 工伤保险 | 0% | 全部由单位缴纳 |
| **社保个人合计** | **10.5%** | |

**住房公积金**：单位和个人缴存比例均为 **5%–12%**，由单位确定（南京住房公积金管理中心 2026-07）。
⚠️ **比例一定要问清楚**——8% 和 5% 差得很远，而且单位缴的部分也是你的钱。

**2026 年缴费基数**
- 社保基数上下限：**5025 元 – 25127 元**（江苏省四部门联合通知，南京市政府官网 2026-10-10）
- 公积金基数上下限：**2660 元 – 42400 元**（南京住房公积金管理中心 2026-07）
- 规则：本人上月平均工资低于下限按下限缴，高于上限按上限缴

> 🚨 **缴费基数应按你本人上年度月平均工资如实申报**，社会保险费要求足额缴纳，长期按最低基数申报不符合规定。对你的直接影响是入账变少：公积金、医保个人账户和养老金账户都按缴费基数计算，基数被压低，这三笔钱同时缩水。**这只是缴费口径问题，不构成对某家公司的定性结论**。入职后可以在社保 / 公积金 App 查自己的实际缴费基数，与自己上月工资对不上时，先向单位人事书面询问申报口径，仍未更正的再向参保地社保经办或稽核部门反映（12333）。

**到手估算示例：月薪 8000 元，南京，公积金 8%，无专项附加扣除**

| 项目 | 金额 | 计算口径 |
|---|---|---|
| 税前月薪 | 8,000 | — |
| 养老 8% | −640 | 8000×8% |
| 医疗 2% | −160 | 8000×2% |
| 失业 0.5% | −40 | 8000×0.5% |
| 公积金 8% | −640 | 8000×8% |
| **五险一金扣除** | **−1,480** | |
| 应纳税所得额 | 1,520 | 8000 − 1480 − 5000（起征点） |
| 个税 | ≈45.6 | 1520×3% |
| **到手约** | **≈6,474** | 8000 − 1480 − 45.6 |

> 💡 **别忘了领你自己的钱**：若享受**住房租金专项附加扣除**（南京属省会城市，标准 **1500 元/月**），应纳税所得额降至 20 元，个税 ≈0.6 元，**到手 ≈6,519 元**。
> 另外，公积金账户里单位 + 个人共 **1280 元/月** 是你的钱，可用于租房提取或购房。

**应届生能用的个税专项附加扣除**

- ✅ **住房租金**：南京 **1500 元/月**（最常用，入职后立刻在个税 App 申报）
- ✅ **继续教育**：学历教育期间 400 元/月（最长 48 个月）
- ⚠️ 住房贷款利息：1000 元/月（**与租金不可同时享受**，应届生极少适用）
- ⚠️ 赡养老人：独生子女 3000 元/月（需父母年满 60 周岁）

（个税起征点 5000 元/月依据《个人所得税法》2018 年修订版，现行有效）

## 二十、Offer 决策：多个 offer 怎么选

### 20.1 加权打分框架

对每个 offer 按 1–5 分打分，加权求和后排序：

| 维度 | 权重建议 | 关注点 |
|---|---|---|
| **薪资总包** | 25% | 底薪×N + 保底奖金 + 补贴，**而非"综合年薪"** |
| **成长性** | 20% | 技术栈前景、导师制度、晋升通道、培训资源 |
| 平台 / 行业 | 15% | 公司规模、行业趋势、**简历背书价值** |
| 团队 / 直属领导 | 15% | 面试中与 leader 的交流感受、团队氛围 |
| 加班强度 / WLB | 10% | 脉脉 / 牛客搜真实评价；**JD 写"抗压能力强"通常是信号** |
| 通勤 / 地点 | 5% | 单程 >1 小时显著影响生活质量 |
| 公司稳定性 | 10% | 见第八节的核查方法 |

> **核心原则：第一份工作优先选"能让你下一份工作更好找"的那个。**

### 20.2 大厂 vs 小公司

- **大厂**：流程规范、背书强、成长体系完善；但螺丝钉化、晋升竞争激烈。**适合第一份工作建立职业基础和规范意识。**
- **小公司**：可能接触更多业务全貌、成长快；但风险高、制度不完善。
  **选择前提**（三条至少满足两条）：创始人背景可靠；有明确盈利模式或稳定融资；核心团队稳定。

### 20.3 外包 / 劳务派遣：应届生尽量避开

**识别标志**
- 合同签约方不是实际工作单位，而是"XX 人力资源有限公司""XX 信息技术有限公司"
- JD 或面试中出现"**驻场**""外派""派驻甲方"
- 薪资由第三方发放、社保由第三方缴纳
- 工牌 / 邮箱后缀与甲方不一致

**核心风险**
- 劳动关系在派遣公司，不在实际用工单位，**维权对象模糊**
- 同工同酬在实践中难落实，福利 / 晋升 / 培训通常与正式员工隔离
- 项目结束可能被退回派遣公司，**待岗期间仅发最低工资**
- 简历上工作经历归属不清，后续跳槽解释成本高

> **法律规定**：劳务派遣只能在**临时性（≤6 个月）、辅助性、替代性**岗位使用，且不超过用工总量 **10%**（《劳务派遣暂行规定》第 4 条）。**超比例用工本身违规**，这条可以在谈判或维权时用。
> ⚠️ 如果确实要考虑外包，务必确认：合同期限 ≥2 年（法定最低）、同工同酬条款写入合同、退回后的待遇保障。

# 第四部分 签合同：劳动合同陷阱与规避（应届生专用）

> **核心原则：签字之前，每一条都看；空白页、空白栏不要签字；口头承诺 ≠ 合同效力；凡是对你不利、看不懂的条款，直接提修改，不改可以不签。**
> 提示：下面很多坑在小微企业、初创公司高频出现。

## 二十一、薪资相关陷阱（最高发）

### 陷阱 1：合同只写极低基本工资，绩效、奖金规则完全空白

**示例**：合同写基本工资 2280（南京旧最低工资），HR 口头说月薪 8K，剩下都是绩效、项目奖。
**风险**：公司后续随便打分、扣绩效；项目回款不顺直接扣钱，你很难维权。
✅ **规避**
1. 要求在合同 / 附件（**薪酬确认单，双方盖章**）写明：固定工资、保底绩效；浮动绩效的考核标准、计算公式
2. 明确**绩效扣除的条件、复核渠道**，不能写"公司可根据经营情况随意调整绩效"
3. 谈薪时提高固定底薪占比

> ⚠️ **2026 年南京最低工资已上调至 2660 元/月**（苏人社规〔2025〕3 号，2026-01-01 起执行）。看到合同写低于这个数的基本工资，直接拒绝。

### 陷阱 2："年终奖、项目奖不属于工资，公司有权酌情发放"

很多合同小字自带这句话。
**风险**：哪怕往年一直发，今年公司一句话就可以不发，仲裁很难支持你。
✅ **规避**
1. 年终奖、13 薪想要保障，**必须写进盖章 offer 或薪酬附件，写明发放时间、发放条件**
2. 如果对方不肯写，你心里默认：**年终奖是惊喜，不是稳定收入**，不要算进每月刚需

### 陷阱 3：补贴（餐补、交通补）约定为"公司福利，可随时取消"

✅ **规避**：如果补贴是你选择这份工作的重要理由，要求写明**发放标准、发放周期**；没写就默认随时会取消。

## 二十二、试用期陷阱

### 陷阱 1：单独签一份《试用期合同》

法律上没有"单独试用期合同"这回事。签了这份合同，**试用期直接无效，该段时间视为正式用工**。很多公司用来压低工资、方便辞退。
✅ **规避**：**劳动合同里面包含试用期条款，绝不单独签试用期合同。**

### 陷阱 2：试用期时长违法

**法定上限（《劳动合同法》第 19 条）**

| 劳动合同期限 | 试用期上限 |
|---|---|
| 不满 3 个月 / 以完成一定工作任务为期限 | **不得约定试用期** |
| 3 个月以上不满 1 年 | ≤ **1 个月** |
| 1 年以上不满 3 年 | ≤ **2 个月** |
| 3 年以上固定期限 / 无固定期限 | ≤ **6 个月** |

- **同一用人单位与同一劳动者只能约定一次试用期**（不能"再试用一次"）
- **超期约定的试用期无效**，超出部分按转正工资补差（第 83 条）

### 陷阱 3：试用期工资低于转正 80%，或低于当地最低工资

**法定底线（第 20 条 + 《实施条例》第 15 条）**：三者取**最高值**——
① ≥ 本单位相同岗位最低档工资的 80%；② ≥ 合同约定工资的 80%；③ ≥ 当地最低工资标准（**南京 2660 元/月**）。
✅ **规避**：低于底线直接拒绝。

### 陷阱 4：无限扩大"录用条件"，方便随便辞退你

**条款示例**："甲方可根据主观评价判定乙方不符合录用条件，解除合同无需补偿"
**风险**：试用期把你开掉，不给任何补偿。
**法律规则（第 21 条）**：用人单位**必须举证**劳动者"不符合录用条件"才能解除，且应在试用期内作出并**书面通知**。仅以"不合适""表现差"等模糊理由辞退属**违法解除**（可主张 2N）。
✅ **规避**
1. 录用条件必须是**客观、可量化**的（技能、交付指标），不能是领导主观评价
2. **要求对方附上书面录用条件清单作为合同附件**——这一条同时是你日后被辞退时的护身符：没有书面标准 = 违法解除

### 陷阱 5：试用期不给交社保

**属于违法。**《社会保险法》第 58 条：自用工之日起 30 日内必须办理社保登记，试用期包含在劳动合同期内。
✅ **规避**：直接拒绝。已经发生的，可向社保稽核部门投诉要求补缴，并可依《劳动合同法》第 38 条被迫解除 + 主张经济补偿。

## 二十三、岗位、工作地点、调岗外派陷阱（非常容易踩）

**示例条款**
> "乙方同意甲方可根据经营需要，调整乙方工作岗位、工作地点，乙方应当服从安排。"

**风险**：招你来做后端开发，后面把你调去实施驻场、外地出差；或者随意派到别的项目组，你不同意就算你违纪。
✅ **规避**
1. **岗位名称、工作地点写具体**：如"工作地点：南京市××区××路××号××大厦"，不要只写"南京市"
2. **删除无条件调岗条款**；改成：**"调岗需双方协商一致，书面变更劳动合同"**（第 35 条）
3. 如果接受调岗、出差，写明**出差补贴标准、出差周期上限、驻场地点**

## 二十四、加班、工时、加班费陷阱

### 陷阱 1：直接写"岗位实行不定时工作制，无加班费"

> 🚨 **重点：不定时工作制不是公司自己写一句就算数，必须经人社局审批备案！绝大多数小公司没有审批。**

**风险**：写上去之后，你周末、晚上加班，公司拒绝付加班费。
✅ **规避**
1. **问 HR：不定时 / 综合工时有没有人社局审批文件，要求出示。** 没有审批，这条条款无效
2. 标准工时岗位，合同写明：**加班按劳动法支付加班费或安排调休**
3. 警惕话术："研发岗弹性工作制""项目制没有加班费""大家都是自愿留下来学习的"

### 陷阱 2："自愿放弃加班费、自愿加班承诺书"

哪怕你签字，**这个承诺书本身法律无效**，但会增加你后续仲裁的举证难度。
✅ **尽量不要签。** 被逼签了也别慌，无效条款不因签字生效，但要同时开始留存加班证据（见第三十二节）。

## 二十五、服务期、违约金陷阱（应届生重灾区）

> ⚠️ **法律规定：只有两种情况，公司可以和你约定违约金**
> ① 公司出钱给你做**专项技术培训**（外部付费培训，**不是**公司内部新人培训），约定服务期；
> ② **竞业限制**。
> **除此之外，所有违约金条款全部无效！**

**常见坑**
- 内部岗前培训、导师带教，约定不满 2 年离职赔违约金 → **违法，无效**
- 离职就要赔偿"招聘成本""工位成本""项目损失" → **无效**
- 户口落户约定服务期违约金 → **无效**（落户不是专项培训）

✅ **规避**
1. 看到违约金，先看是不是**专项外部付费培训**，有没有**培训发票凭证**
2. 内部培训、入职培训、导师带教，**一律不接受违约金**
3. 真有外部付费培训的，要求写明：培训费用总额（有发票）、服务期年限、违约金按未履行部分**递减**计算

## 二十六、竞业限制（竞业协议）陷阱

> 竞业：离职之后一段时间，不能去竞品公司上班。

**陷阱**
1. 随便给所有技术岗签竞业协议，但**不写竞业补偿金**；或者写"补偿金已包含在平时工资里"（**这种约定无效**）
2. 竞业范围写得极大，几乎整个行业都不能去
3. 期限超过 2 年（**法定上限就是 2 年，超过部分无效**）

**规则要点**
- 竞业生效的前提：**离职后按月支付竞业补偿金**
- 未约定补偿标准的，按劳动者离职前 12 个月**平均工资的 30%** 按月支付，且不低于当地最低工资标准（最高法劳动争议司法解释一）
- **公司不付钱，你不受竞业约束**（一般连续 3 个月未支付可请求解除竞业限制）

✅ **规避**
1. 看清：**竞业补偿金金额、发放时间、发放方式**
2. 范围尽量写**具体竞品名单**，不要写"所有 AI 公司""所有软件公司"
3. **非核心岗位（普通开发、测试）可以直接拒绝签署竞业协议**——你手上根本没有商业秘密，公司让你签只是为了吓唬你
4. 离职时要求公司**书面确认竞业限制是否启动**。不启动就别再拿"竞业"卡你就业

## 二十七、离职相关陷阱

### 陷阱 1："离职必须经过公司审批，不批准不能走"

**条款**："乙方离职，须甲方审批同意，方可离职"
**法律规则（第 37 条）**：转正员工**提前 30 天书面通知**、试用期**提前 3 天通知**，**不需要老板批准，到期即可离职**。这种条款本身无效，但容易制造纠纷、卡离职证明。
✅ **规避**
1. 合同不要接受"必须甲方审批同意方可离职"
2. **保留书面离职提交证据**（邮件、企业微信、EMS 回执）——口头说"我辞职"没用

### 陷阱 2：离职扣押工资、项目奖金、报销

**条款**："发奖前离职，所有未发放奖金自动取消"
✅ **规避**
1. 项目奖金、绩效，如果是你**在职期间劳动所得**，不能单纯因为离职直接清零
2. 面试 / 签约前确认这条，能修改就修改，不能修改作为风险记入你的 offer 评估
3. 工资必须结清，扣工资属违法，可向劳动监察投诉

### 陷阱 3：扣押证件、押金、工装费、培训费

**任何形式入职交钱、押身份证 / 学历证，都是违法，直接拒绝。**
《劳动合同法》第 9 条明文禁止；第 84 条规定扣押证件的由劳动行政部门责令限期退还并处罚款。

## 二十八、知识产权、保密条款（技术岗必看）

**陷阱条款**：**你在职、离职之后，所有自己写的代码、个人作品，全部归公司所有。**
**风险**：把你下班自己业余做的个人项目、开源作品、GitHub 仓库也抢走。

✅ **规避**：要求加上一句补充——
> "不包括乙方在非工作时间、未使用甲方资源、与甲方业务无关的独立开发成果。"

**其他注意**
- 保密条款本身是正常的，但**不要范围无限扩大**（比如"公司一切信息均为商业秘密"）
- **入职前把你自己的开源项目、个人仓库做好时间戳留证**（Git 提交记录本身就是证据），避免日后被主张"在职期间的成果"
- 不要在公司电脑上做个人项目，不要用公司邮箱注册个人开源账号

## 二十九、其他隐形坑

1. **空白合同**：公司让你先签字，说后面再填内容。**绝对不要签！** 签完对方随便填，你说不清。
2. **附件不认**：薪酬单、offer 写的待遇，合同写"本合同效力高于一切口头和书面承诺"，直接把 offer 废掉。
   ✅ 合同写明：**"本合同附件（录用 offer、薪酬确认单）与本合同具有同等法律效力"**
3. **公司主体不一致**：面试 A 公司，签合同是另一家外包子公司 / 第三方人力公司（劳务派遣），工资、社保由第三方发。
   ✅ 核对合同上**甲方全称、统一社会信用代码**，和你面试的公司是不是同一主体；劳务派遣要单独评估风险（见第 20.3 节）。
4. **只给一份合同**：签完字公司说"合同我们统一保管"。
   ✅ **劳动合同必须双方各执一份**，你要索要**盖章后的原件**。不给的，拍照留存所有页面，并在企业微信 / 邮件里跟 HR 确认"我尚未收到合同原件"，留下书面痕迹。

# 第五部分 在职期间：你的法定权益（最容易被侵犯的部分）

## 三十一、五险一金

**法律依据**：《社会保险法》第 58 条（用工 30 日内办理社保登记）、第 60 条（按时足额缴纳，非不可抗力不得缓缴减免）；《劳动法》第 72 条。

- **试用期也必须缴。** 自用工之日起即建立劳动关系。
- 🚨 **"自愿放弃社保承诺书"一律无效。** 最高人民法院《关于审理劳动争议案件适用法律问题的解释（二）》（**2025 年 9 月 1 日施行**）明确：无论双方协商还是劳动者单方承诺，任何"不缴社保"约定均无效。劳动者可据此依《劳动合同法》第 38 条解除合同并**主张经济补偿**。（court.gov.cn/fabu/xiangqing/472691.html）
- **按最低基数缴纳违法。** 缴费基数应为你本人上年度月平均工资；低于省公布下限的按下限执行。**2026 年江苏省社保缴费基数下限 5025 元/月、上限 25127 元/月。**
- **公积金同样强制。**《住房公积金管理条例》第 15、20 条。投诉渠道：南京住房公积金管理中心，**12329 热线**。
- **断缴后果**：医保断缴次月起无法享受统筹报销；连续缴费年限影响购房资格（南京要求连续缴纳社保 / 个税）、落户积分、公积金贷款额度。
- **离职接续**：同城换工作由新单位续缴；跨市 / 跨省通过"国家社会保险公共服务平台"或"江苏智慧人社"App 申请转移；灵活就业可自行到户籍地 / 居住地社保经办机构参保养老和医疗。

> 💡 **入职第一个月就查一次**：江苏智慧人社 App 看社保是否到账、基数是多少；公积金 App / 12329 看缴存比例。发现按最低基数缴或没缴，**当月就提出**，越早越容易解决。

## 三十二、加班与加班费

**法律依据**：《劳动法》第 41 条（**每日加班 ≤3 小时，每月 ≤36 小时**）、第 44 条。

| 加班类型 | 补偿标准 | 能否用调休替代 |
|---|---|---|
| 工作日延时 | ≥ **150%** 工资 | ❌ 不可 |
| 休息日 | ≥ **200%** 工资 | ✅ 6 个月内安排同等时间补休可免付（《江苏省工资支付条例》第 20 条） |
| 法定节假日 | ≥ **300%** 工资 | ❌ **不可**，必须给钱 |

**加班费计算基数（江苏规则，《江苏省工资支付条例》第 64 条）**
① 双方有约定从约定；② 无约定或约定低于集体合同 / 单位制度的，按集体合同或制度执行；③ 均无法确定的，按**前 12 个月平均工资**计算。
**底线：不得低于当地最低工资标准折算的日 / 时工资（南京 2660 元/月，日工资 = 2660÷21.75 ≈ 122.3 元）。**
按月固定发放的岗位工资及与正常出勤挂钩的月度绩效奖金一般应纳入基数；一次性年终奖、特殊环境津贴、非工资性福利补贴通常不纳入。

> 🚨 **996 / 大小周违法。** 996 意味着月加班约 72 小时，远超法定 36 小时上限。**"公司文化如此"不是法律依据。**

**加班证据留存清单（平时就要做，别等被裁了才想起来）**
- 打卡 / 考勤记录截图
- 加班审批单、排班表
- 钉钉 / 企业微信排班与消息截图（**含时间戳**）
- 工作群消息
- **代码提交 / Git 记录**（技术岗最有力的证据）
- 门禁刷卡记录
- 加班时段的外卖 / 打车订单
- 同事书面证言

> ✅ **建议日常备份至个人设备**（注意：只备份能证明你工作时间的记录，不要拷贝公司业务数据，那是另一码事）。

## 三十三、假期

**年休假**（《职工带薪年休假条例》第 3 条）

| 累计工作年限 | 年假天数 |
|---|---|
| 满 1 年不满 10 年 | **5 天** |
| 满 10 年不满 20 年 | 10 天 |
| 满 20 年 | 15 天 |

- 应届生入职当年**按剩余日历天数折算**（≥1 天即可享受）
- **未休年假**：用人单位应按**日工资 300%** 支付报酬（其中含正常工资，即**额外补 200%**）

**江苏省假期一览（现行有效，《江苏省人口与计划生育条例》第 24 条，2021 年修正；苏发〔2022〕8 号）**

| 假期类型 | 天数 |
|---|---|
| **婚假** | 国家 3 天 + 江苏延长 10 天 = **13 天** |
| **产假** | 国家 98 天 + 江苏延长 60 天 = **158 天**；难产 +15 天；多胞胎每多 1 个 +15 天 |
| **男方护理假** | **15 天** |
| **育儿假** | 子女 3 周岁前，夫妻**每年各 10 天** |
| 丧假 | 直系亲属 3 天（国家统一规定） |

> 以上假期**视为出勤，照发工资**，国家法定休假日不计入假期天数。（江苏省人大 jsrd.gov.cn）

## 三十四、工资支付与病假医疗期

**《江苏省工资支付条例》要点**
- 工资必须以**货币形式按月支付**（第 10 条），不得以实物或有价证券替代
- **不得克扣或无故拖欠工资**（第 9 条）
- **病假工资：不低于当地最低工资标准的 80%**（第 27 条）。2026 年南京一类地区最低工资 2660 元，即**病假工资 ≥2128 元/月**

**医疗期**
- 长度（《企业职工患病或非因工负伤医疗期规定》）：实际工作年限 <10 年且本单位工龄 <5 年 → **3 个月**；本单位工龄 ≥5 年 → **6 个月**
- 🚨 **医疗期内不得辞退。**《劳动合同法》第 42 条：在规定医疗期内，用人单位不得依第 40、41 条解除劳动合同。违法解除的可主张 **2N 赔偿金**
- 同样受第 42 条保护的还有：**孕期、产期、哺乳期女职工**；在本单位连续工作满 15 年且距退休不足 5 年的

# 第六部分 离开时：被辞退、辞职与补偿金

## 三十五、N / N+1 / 2N 速查表

| 类型 | 适用情形 | 计算公式 | 法律依据 |
|---|---|---|---|
| **N（经济补偿）** | 协商解除（**单位提出**）、第 40 条无过失辞退、第 41 条经济性裁员、合同到期单位不续签（或不维持/提高原条件）、劳动者依第 38 条**被迫解除** | 工作年限 × 月工资 | 《劳动合同法》第 46、47 条 |
| **+1（代通知金）** | **仅限**第 40 条三种情形（医疗期满不能工作、不胜任经培训/调岗仍不胜任、客观情况重大变化），且**未提前 30 日书面通知**时 | 额外 1 个月工资 | 《劳动合同法》第 40 条 |
| **2N（赔偿金）** | **违法解除 / 终止**（无正当理由、程序违法、辞退孕期 / 医疗期员工等） | 2 × 经济补偿标准 | 《劳动合同法》第 48、87 条 |

**N 的计算口径（第 47 条）**
- 每满 1 年 → 1 个月工资
- **6 个月以上不满 1 年 → 按 1 年算**
- 不满 6 个月 → 半个月工资
- "月工资" = 解除 / 终止前 **12 个月的平均应得工资**（含奖金、津贴、补贴等全部货币性收入，**税前**）
- **封顶规则**：月工资 > 当地上年度职工月平均工资 **3 倍**的，按 3 倍计算，且年限最高 **12 年**

## 三十六、应届生能拿多少钱（照这个算）

> **示例**：2026 年 7 月入职南京某公司，月薪 8000 元，2027 年 3 月被辞退（工作 8 个月）。
> - 合法辞退（协商解除 / 无过失辞退）：**N = 1 个月工资 = 8000 元**（6 个月以上不满 1 年按 1 年算）
> - 若属第 40 条情形且未提前 30 天通知：**N+1 = 16000 元**
> - 若属**违法解除**（无书面录用条件就说你"不符合"、程序违法等）：**2N = 16000 元**

> **社平工资参考**：南京市 2025 年城镇非私营单位从业人员年平均工资 **165111 元**，折合月均约 **13759 元**。（南京市统计局 2026-06-25 发布，tjj.nanjing.gov.cn）
> ⚠️ 经济补偿金封顶基数 = 13759 × 3 ≈ **41277 元/月**。应届生薪资通常远低于此，**无需担心封顶**。

## 三十七、公司不想给钱的套路与你的反制

### 37.1 不需要补偿的 6 种情形（《劳动合同法》第 39 条）

① 试用期被**证明**不符合录用条件；② **严重**违反规章制度；③ 严重失职 / 营私舞弊致重大损害；④ 同时与其他单位建立劳动关系且拒不改正；⑤ 以欺诈 / 胁迫手段订立合同；⑥ 被追究刑事责任。

**公司最爱滥用前两条，反制方法：**

| 公司说法 | 你的反制 |
|---|---|
| "你试用期不符合录用条件" | 要求出示**入职时你书面确认过的录用条件**，以及考核不合格的**客观证据**。**无书面标准 = 违法解除，主张 2N** |
| "你严重违反公司制度" | 要求出示**经民主程序制定并已公示**的规章制度（《劳动合同法》第 4 条）。**未经公示的制度不能作为解除依据** |
| "你能力不行，不胜任" | 第 40 条要求**先培训或调岗，仍不胜任**才能解除，且要 N+1。直接辞退 = 违法解除 |

✅ **万能应对话术**：
> "请出具**书面解除通知书**，写明解除依据的事实和法律条款。我会依法主张我的权利。"

### 37.2 "劝退话术"应对表——这一节最重要

| HR 说 | 真相 | 你该怎么答 |
|---|---|---|
| **"你自己写辞职信吧，好聚好散，不影响背调"** | **主动辞职 = 一分钱补偿都没有** | **绝不主动写辞职信。** "我不打算主动离职。如果公司认为需要解除合同，请出具书面解除通知。" |
| "主动离职的话给你多一个月" | 口头承诺无法律效力，辞职信一交就翻脸 | "补偿方案请写进**双方盖章**的解除协议，我签字后即刻办理交接。" |
| "不接受就没有背调好评 / 让你在这行混不下去" | 这是施压话术；是否构成侵权要结合证据和裁判机关的认定，**不当场争论定性** | **录音留证**（只录你自己参与的对话）。"我不评价这句话，我们回到补偿方案上。" |
| "公司困难，大家共渡难关，你先签了这个" | 让你签的往往是"双方无任何争议"的放弃声明 | "我需要时间看清楚，先不签。"（见第 43 节实操提醒） |
| "调岗到外地，不去就算你自动离职" | 变相辞退，规避补偿 | "调岗需协商一致并书面变更合同（第 35 条）。我不同意，请按正常流程处理。" |

### 37.3 反过来用：被迫解除（《劳动合同法》第 38 条）

公司存在以下情形，**你可以主动解除并主张 N**（这是"主动辞职也能拿钱"的唯一合法路径）：

① 未按约定提供劳动保护或劳动条件；② **未及时足额支付劳动报酬**；③ **未依法缴纳社会保险费**；④ 规章制度违法损害你的权益；⑤ 以欺诈 / 胁迫手段订立合同；⑥ 以暴力、威胁或限制人身自由强迫劳动。

**正确操作步骤**
1. 向公司发送**书面《被迫解除劳动合同通知书》**，**列明具体违法事实和法律条款**（如"公司自 2026 年 8 月起未依法缴纳社会保险，依据《劳动合同法》第 38 条第 3 项，本人决定解除劳动合同"）
2. **用 EMS 寄送并保留回执**，同时邮件 / 企业微信发一份留痕
3. 办理工作交接，索要离职证明
4. 申请劳动仲裁主张经济补偿

> 🚨 **注意顺序**：必须**先发被迫解除通知，再走人**。如果你先写了"个人原因辞职"，再想主张 38 条就非常被动了。

## 三十八、离职必办清单

1. **离职证明**：《劳动合同法》第 50 条规定**必须开具，不得附加任何条件**（不能说"你先签放弃声明才给"）。拒开可向劳动监察投诉，因此造成你无法入职新单位的损失可主张赔偿。
2. **工资结清**：当月工资 + **未休年假折算工资（300%）** + 加班费 + 应得奖金
3. **社保 / 公积金转移**：同城自动接续；跨地区线上办理
4. **档案转递**：持离职证明到人才服务中心办理，**公对公，不要自己拿**
5. **竞业限制书面确认**：是否启动、期限、补偿标准。未约定补偿的，按离职前 12 个月平均工资 **30%/月** 支付
6. **工作交接**：签署书面交接清单，双方签字确认，**自留一份**（防止日后被说"交接不清造成损失"）
7. **股权 / 期权**：查阅授予协议中关于离职处理的条款，书面确认归属与行权安排
8. **个人物品与账号**：清理个人文件（**不要拷贝公司数据**），退出个人账号登录

## 四十、证据：你唯一的武器

**证明劳动关系存在的证据（任一即可，越多越好）**
劳动合同、工资银行流水、社保缴费记录、工牌 / 胸卡、考勤记录、钉钉 / 企业微信截图、工作邮件、入职登记表 / Offer、报销单据、同事书面证言。

> ⚠️ **没签劳动合同怎么办？** 用工超过 1 个月不满 1 年未签书面合同的，公司应支付**二倍工资**（第 82 条）；满 1 年未签视为已订立**无固定期限劳动合同**（第 14 条）。用上面这些证据照样能证明事实劳动关系。

**电子证据固定**
- 聊天记录 / 邮件：**录屏 + 截图**（显示完整对话和时间戳），有条件可做公证或可信时间戳认证
- **录音取证的合法边界（先看这里，再决定录不录）**：《最高人民法院关于适用〈中华人民共和国民事诉讼法〉的解释》（2022 年修正）第一百零六条——以**严重侵害他人合法权益**、**违反法律禁止性规定**或**严重违背公序良俗**的方法形成或获取的证据，不能作为认定案件事实的根据。实践中通常区分"录制自己参与的对话"与"窃听他人对话"；各地、各仲裁委与法院的采信尺度有差异，**以受理机关的判断为准，不要把别处"录音一定管用"的说法当作保证**。
  - ✅ **可以做**：录制**你自己参与**的谈话（离职沟通、绩效面谈、辞退通知），不必先取得对方同意即可留存并提交；谈话开始时自然带出日期、在场人身份与事由（"张经理，今天是 3 月 5 号，关于公司提出解除合同这件事……"）便于佐证；**全程连续录制、当天原始文件不剪辑**，并单独记一份时间线（时间、地点、在场人、对方原话要点）。
  - 🚫 **不可以做**：录制他人之间的对话；在他人工位、会议室、私密空间放置录音设备；**诱导对方说出你想要的话**（设套提问、替对方"补台词"、反复暗示期望答案）——这类内容证明力低且属不正当取证；剪辑、拼接后当作完整记录提交。
  - 🚫 **红线**：不得伪造、毁灭证据，不得以他人隐私或内部资料相要挟索取利益（《民事诉讼法》第一百一十四条、《刑法》相关条款，详见《公开发布与免责合规手册》第六节）。

## 四十二、法律援助：没钱也能打官司

- **12348 热线**：免费法律咨询，**打之前把事实和时间线整理清楚**，效率高很多
- **法律援助中心**：各区司法局下设，经济困难标准参照当地低保线。**请求确认劳动关系、支付劳动报酬、给予社会保险待遇等属于法律援助范围**（《法律援助法》第三十一条）；经济补偿金类主张是否受理，以当地法律援助机构答复为准
- **律师费用参考**：简单劳动仲裁案件代理费常见 **3000–8000 元**（**仅为地区性参考，各地、各律所差异很大，请以本地两三家律所的实际报价为准**）；部分律师接受**风险代理**（胜诉后按比例收费，前期不花钱或很少）
- 💡 **先做免费的一步再决定**：劳动仲裁申请本身不收费，是否自行参加取决于**证据复杂度和主张金额**。金额不大、事实清楚（如欠薪、未出具离职证明）时可以自行申请；涉及加班费计算、补偿金基数、举证责任分配时，先用 12348 或法律援助中心做一次免费评估，再决定要不要委托律师。**以上是渠道与费用信息，不构成针对你个案的法律意见。**

## 四十三、实操提醒（这些错一犯就前功尽弃）

1. 🚨 **不要签"双方无任何争议""一次性了结"的和解协议**，除非已经算清所有应付金额（工资 + 加班费 + 未休年假 + 补偿金）。**签字后极难再主张。**
2. 🚨 **仲裁期间不要删除工作群 / 聊天记录。** 这是核心证据。被踢出群前先把记录导出来。
3. 🚨 **离职交接单上不要写"无争议""双方权利义务终止"。** 只确认**交接事实**，不确认权利义务终结。
4. **遇到威胁"让你在这个行业混不下去""背调给你差评"**：先按施压话术处理——**不争论、不回应定性，把自己参与的这段对话录下来留证**（边界见第四十章）。事后可向对方书面确认这句话的意思，保留回复。若对方确实向背调机构或同行**散布与事实不符的内容**，可能涉及对你名誉权的侵害（《民法典》第一千零二十四条）；**是否成立、以什么案由主张，需结合证据由裁判机关认定，先咨询 12348 或法律援助中心**，不要自己先下结论。
   （如实反馈离职原因一般不构成侵权；**捏造事实、恶意贬损**才可能构成）
5. **所有沟通尽量书面化。** 口头承诺不等于法律义务。重要事项用邮件 / 短信确认，保留原件。
6. **不要情绪化裸辞。** 走之前先把证据固定好、把被迫解除通知发出去、把年假和工资算清楚。
7. **时效别忘了。** 一般争议 1 年，从你知道权利被侵害那天起算。**不确定就先申请仲裁，宁早勿晚。**
