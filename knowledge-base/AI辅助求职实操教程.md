## 第一步：简历准备（AI优化的前提）

### 1.1 简历的底层逻辑

HR看一份简历平均6秒，你的简历必须在6秒内回答三个问题：

1. 你能做什么岗位？（匹配度）
2. 你做过什么？（项目经验）
3. 你比别人强在哪？（量化成果）

### 1.2 简历结构（软件岗标准版）

```
基本信息（姓名、电话、邮箱、GitHub/博客）
求职意向（一句话：求职Java后端开发/软件测试方向）
教育背景（学校、专业、GPA、相关课程）
专业技能（分点列：语言、框架、工具，按熟练度排序）
项目经历（2-3个核心项目，STAR写法）
实习经历（如有）
证书/竞赛/获奖（国奖、竞赛、软件著作权等）
```

### 1.3 AI优化简历的正确姿势

**不要直接让AI重写你的简历**，要分步骤喂给AI：

**第一步：提取你真实的项目素材**

- 把你做过的项目、课程设计、竞赛项目，全部列出来
- 每个项目写：你用了什么技术、做了什么功能、解决了什么问题、有没有量化结果

**第二步：让AI对照JD改写**

- 先拿到目标岗位的JD（Job Description）
- 把JD+你的项目素材一起喂给AI
- 要求AI：按JD关键词调整项目描述的顺序和措辞，量化成果

**第三步：人工审核（必须做）**

- 所有AI生成的内容，你要能讲出来
- 面试会深挖每一个项目细节，写了你没做过的东西=面试翻车

### 1.4 简历定制5原则（借鉴 GitHub 官方 technical-job-search）

针对具体岗位定制简历时，遵守这5条：

1. **精确匹配用词**：JD写"分布式系统"就写"分布式系统"，不要写同义词"大规模系统"。ATS和面试官都在找关键词匹配。
2. **以影响开头**：每条经历要有结果——"将P99延迟降低40%"，不是"参与了性能优化"。公式：动作+做法+量化结果。
3. **尽量量化**：用户量、QPS、团队规模、节省成本、带来收入。应届生可量化项目规模、竞赛排名、实习产出。
4. **删减不匹配的**：针对这个岗位的2页简历 > 海投的4页通用简历。无关经历删掉或压缩，技术栈按JD要求排序。
5. **匹配职级信号词**：应届生用"实现了/参与了/优化了"，不要用"主导架构"这种高级别词。

> 详细的JD分析+简历定制流程见 `.claude/skills/jd-analysis-and-resume-tailoring/SKILL.md`

### 1.5 简历避坑

- ❌ 不要用花哨模板，PDF格式，一页最好（应届生）
- ❌ 不要写"熟练使用Office"这种废话
- ❌ 不要把课程设计吹成"大型项目"，HR一眼看穿
- ✅ GitHub链接一定要放，有真实代码比什么都强

## 第二步：渠道选择

### 2.1 三条渠道并行策略

不要只走一个渠道，三条线同时推进，效率最高：

| 渠道                       | 优势                 | 劣势               | 适合目标          |
| ------------------------ | ------------------ | ---------------- | ------------- |
| **学校渠道**（就业网、双选会、老师内推）   | 骗子少、接受应届生、能开实习证明   | 优质技术岗少、薪资低、范围窄   | 保底、第一份实习、学分实习 |
| **自主投递**（BOSS直聘、牛客、企业官网） | 岗位多、选择广、能接触大厂/AI公司 | 虚假岗位多、需要自己排雷     | 冲优质技术岗、高薪岗    |
| **AI辅助筛选**（用AI批量分析岗位、排序） | 效率高、快速匹配度打分、自动识别坑岗 | 需要你自己提供数据、不能完全依赖 | 批量投递前的初筛      |

### 2.2 学校渠道怎么用

1. **先问辅导员**：能不能自主找实习？还是必须走校企合作？
2. **优先找老师内推**：专业课老师手里常有合作企业，内推通过率远高于海投
3. **双选会重点看**：高新技术企业、专精特新企业、有自研产品的公司
4. **避开**：纯销售岗、无薪实习、要求长期驻场的外包岗

### 2.3 自主投递怎么用

**平台优先级：**

1. **牛客网**：技术岗最多、校招信息最全、有面经可查
2. **BOSS直聘**：可以直接和HR聊、回复快
3. **企业官网**：大厂、知名公司直接投官网
4. **智联/前程无忧**：传统行业、政企类公司多

**投递技巧：**

- 每天固定投5-10家，不要一次投50家（精力分散）
- 投递前先查公司（用后面的尽调流程）
- 打招呼消息不要用模板，简单说"我做过XX项目，和贵公司XX岗位匹配"

## 第三步：AI辅助投递与筛选

### 3.1 AI能帮你做什么

1. **批量分析JD匹配度**：把你的简历+多个JD一起喂AI，让AI打分排序
2. **生成定制化打招呼消息**：针对每个岗位写不同的开场白
3. **识别坑岗**：让AI分析JD里的危险信号（培训贷、外包、996）
4. **整理投递追踪表**：记录投了哪些、什么时间、HR回复没

### 3.2 批量岗位匹配流程

```
步骤1：收集10-20个目标岗位的JD文本
步骤2：把你的简历（纯文本）+ 所有JD一起喂给AI
步骤3：让AI输出一个表格，列：公司名、岗位名、匹配度分数、优势、差距
步骤4：按匹配度从高到低排序，优先投70%以上匹配的
```

### 3.3 坑岗识别清单（让AI帮你扫）

出现以下信号，直接跳过：

- "无经验可培训" + "岗前培训" → 大概率培训贷
- "接受应届生" + 薪资特别高（南京开发岗起薪15K+）→ 假岗位
- "弹性工作制" + "能接受加班" → 996预警
- "项目驻场" + "接受出差" → 外包驻场
- 公司名里带"人力资源"、"劳务" → 劳务派遣

## 第四步：公司尽调排雷

> 这是最关键的一步！**所有渠道拿到的offer，都必须先尽调再决定去不去**  
> 对应本地skill：`company-due-diligence`

### 4.1 为什么要尽调

- 学校渠道 ≠ 靠谱（学校只是初审，不兜底）
- BOSS上的公司 ≠ 真实（很多包装很好的小公司）
- 口碑、风险、加班、薪资发放，这些信息JD上不会写

### 4.2 尽调必查5个维度

| 维度       | 查什么                   | 怎么查            |
| -------- | --------------------- | -------------- |
| **工商基础** | 成立时间、注册资本、参保人数、法定代表人  | 企查查/天眼查/启信宝    |
| **司法风险** | 失信、被执行、欠税、行政处罚、劳动纠纷   | 中国执行信息公开网、信用中国 |
| **业务模式** | 自研还是外包？主要客户是谁？最近中标项目？ | 公司官网、政府采购网     |
| **员工口碑** | 加班情况、薪资发放、管理混乱度       | 脉脉、职友集、牛客、知乎   |
| **资质荣誉** | 高新技术企业、专精特新、软著数量      | 高新技术企业认定网      |

### 4.3 风险评级标准

- 🔴 **高风险（直接放弃）**：失信被执行人、大额欠税、大量劳动纠纷、参保人数<10且成立超3年
- 🟡 **中风险（谨慎选择）**：有历史风险但已结清、规模小但业务稳定、口碑两极分化
- 🟢 **低风险（优先考虑）**：成立5年以上、规模稳定、无重大风险、口碑正面

### 4.4 尽调结果怎么用

- 高风险公司：薪资再高也不去，大概率拖欠工资或裁员
- 中风险公司：可以去，但谈薪时优先锁定基本工资，不要信年终奖
- 低风险公司：可以谈总包（base+奖金+福利），重点看成长空间

## 第五步：面试准备与模拟

### 5.1 技术岗面试准备清单

**开发岗：**

- 计算机基础：Java/Python核心、数据结构、常用算法
- 项目深挖：你简历上的每个项目，能讲清楚技术选型、难点、优化
- 框架：SpringBoot/Vue/数据库，常见面试题
- 手撕代码：简单的增删改查、排序、字符串处理

**测试岗：**

- 测试基础：等价类、边界值、用例设计方法
- 数据库：SQL增删改查、关联查询
- 自动化：Selenium/Pytest基础概念
- 项目：你测过什么系统、发现过什么bug

**运维岗：**

- Linux常用命令、Docker基础、Nginx反向代理
- Shell脚本、Git操作
- 监控、部署、故障排查思路

### 5.2 AI模拟面试

用AI扮演面试官，反复练习：

1. 让AI根据你的简历+岗位JD，生成10个面试问题
2. 你逐个回答，AI点评：哪里好、哪里要改进
3. 重点练习：自我介绍、项目介绍、为什么选我们公司、你的优缺点

### 5.3 面试时反向提问（必须问）

不要等HR问"你有什么问题"就说没有，一定要问：

1. 这个岗位是做什么项目的？技术栈是什么？
2. 团队有多少人？我的直属领导是谁？
3. 试用期多久？转正考核标准是什么？
4. 加班情况怎么样？加班费/调休怎么算？
5. 社保公积金按什么基数交？

## 第六步：谈薪与offer谈判

> 对应本地skill：`salary-negotiation`

### 6.1 谈薪核心原则

- **先不要先报数字**：让HR先说预算范围
- **小微企业优先保基本工资**：不要用底薪换年终奖承诺
- **所有口头承诺都不算数**：必须写进offer

### 6.2 分公司类型的谈薪策略

**小微企业（20-50人，项目制）：**

- 优先级：基本工资 > 社保基数 > 公积金 > 补贴 > 年终奖
- 不要信"年终奖3-6个月"，按没有年终奖算总包

**中型公司（50-200人，有自研产品）：**

- 优先级：基本工资 + 固定奖金 > 社保公积金 > 成长空间
- 可以争取：签字费、额外年假、更高的公积金比例

**大厂/知名公司：**

- 优先级：总包（base+股票+福利）> 平台背书 > 成长空间
- 重点谈：级别、股票数量、签字费

### 6.3 常见压价话术应对

| HR话术           | 应对话术                     |
| -------------- | ------------------------ |
| "你期望薪资多少？"     | "我想先了解一下这个岗位的预算范围"       |
| "这已经是我们能给的最高了" | "这个最高是指基本工资还是总包？"        |
| "年终奖有3-6个月"    | "过去两年实际发了几个月？写不写进offer？" |
| "我们大小周弹性工作"    | "加班有加班费吗？调休能正常休吗？"       |

## 第七步：合同与offer校验

### 7.1 拿到offer后必须核对的清单

- [ ] 基本工资：多少？发放日？
- [ ] 绩效工资：占比？考核标准？保底多少？
- [ ] 试用期：几个月？工资打几折？
- [ ] 社保：基数多少？从什么时候开始交？
- [ ] 公积金：交不交？基数？比例？
- [ ] 年终奖：几个月？写不写进offer？
- [ ] 工作时间：双休/大小周？加班怎么算？
- [ ] 工作地点：具体地址？会不会随便调岗？

### 7.2 劳动合同常见陷阱

1. **空白合同**：绝对不要签，所有空白都要填好
2. **薪资只写最低工资**：口头承诺不算数，要求写清楚
3. **无条件调岗条款**："公司可根据需要调岗" → 要求改成协商一致
4. **违约金乱加**：只有专项培训和竞业限制能约定违约金
5. **放弃社保承诺书**：签了也无效，但尽量不签
6. **合同不给你一份**：必须索要盖章后的原件

### 7.3 实习协议特殊注意

- 在校生实习签的是《实习协议》，不是劳动合同
- 必须写清楚：实习补贴、工作时间、加班补贴、实习证明发放
- 无薪实习（长期、全职）要警惕，相当于免费劳动力

## 用 AI 之前：把不该给出去的东西摘掉

AI 工具会把你的输入送到第三方服务器，**这一步做不好，后面所有优化都不值得**。

| 提交前必须处理 | 怎么做 | 为什么 |
|---|---|---|
| 自己的身份证号、银行卡号、家庭住址、证件照 | 全部删除，只留姓名 + 邮箱 + 城市 | 这些对求职判断毫无用处，泄露了却不可撤回 |
| **别人的信息**：推荐人姓名电话、同学/前同事姓名、客户或供应商名称 | 改成角色称谓（"推荐人：前直属上级"、"客户：某股份制银行"） | 你没有取得他们同意把他们个人信息交给第三方处理，风险由你承担（详见《公开发布与免责合规手册》第四节） |
| 公司未公开材料：内部文档、代码、架构图、数据库导出、报价单、内网截图 | **不要上传**；只描述你做了什么、用什么技术、达成什么可公开的结果 | 可能同时违反保密条款与竞业期义务，且属于商业秘密范围 |
| 劳动合同、竞业协议原文 | 只贴你要问的那一条条款，并先把公司全称、你的姓名与证件号替换为 XX 公司 / 张三 | 合同是含双方身份的文件；整份上传等于把两份个人信息一起交出去 |
| 在职状态、薪资流水、offer 截图 | 用文字表格重写（税前 10000／公积金 5%），不用原图 | 截图常含公司抬头、公章、姓名，事后无法收回 |

**三条使用纪律**：

1. **AI 给的是草稿，不是事实**。所有薪资、政策、法条、公司信息必须回到真实检索与知识库来源；AI 说不出来源的数字一律不用（全库铁律）。
2. **AI 不知道你的处境**。方向、身份（🎓/💼）、底线这些要先由你自己讲清楚，否则它会按平均情况给你平庸建议。
3. **署名与责任在你**。用 AI 写的简历、求职信、公开帖子，出了问题是你签的字；发布前自己通读一遍，删掉它编造的、夸大的、以及可能冒犯具体个人的表述。

```
你是资深HR，帮我优化简历。

[粘贴你的简历纯文本]

目标岗位JD：
[粘贴JD文本]

请帮我：
1. 按JD关键词调整项目描述的顺序和措辞
2. 把项目成果量化（数字、百分比、效率提升）
3. 输出优化后的完整简历（一页版）

```
你是求职顾问，帮我评估匹配度。

我的简历：
[粘贴简历]

以下是10个岗位的JD：
[粘贴JD1]
[粘贴JD2]
...

请输出一个表格：
| 公司 | 岗位 | 匹配度(%) | 我的优势 | 我的差距 | 建议投递优先级 |

按匹配度从高到低排序。
```

### 模板3：公司尽调辅助

```
你是求职风险顾问。我准备入职 [公司名]，已知信息如下：
[粘贴你查到的工商、司法、口碑信息]

请帮我：
1. 总结这家公司的核心风险点
2. 给出风险评级（🔴高/🟡中/🟢低）
3. 列出面试时必须问清楚的5个问题
4. 给出谈薪优先级建议（这家公司应该优先争取什么）
```

### 模板4：谈薪话术生成

```
我拿到了 [公司名] 的offer，情况如下：
- 基本工资：X K
- 绩效：X K（占X%）
- 年终奖：X 个月（口头/书面）
- 社保基数：X
- 试用期：X 个月
- 公司风险等级：🔴/🟡/🟢

请帮我：
