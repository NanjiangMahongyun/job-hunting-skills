# 求职信息渠道与数据源清单（知识库）

> 适用：job-recommender（岗位推荐）、company-due-diligence（公司尽调）、industry-background-analyzer（行业分析）——三个 skill 的「去哪搜、能搜到什么」由本文件回答。
> 核心原则：**所有数据必须来自检索，搜不到写「未查到」，禁止编造。** 本清单给的是入口，不是结论；知道渠道不等于拿到了数据。
> 来源：以下地址均在 2026-10-22 用 WebSearch / WebFetch 逐条核实过。核实不了、或会被反爬拦截的渠道，只写机构名与检索方法，不给 URL。

---

## 〇、三条通用规则

| 规则 | 说明 |
| --- | --- |
| 交叉验证 | 单一来源不写成事实。工商/司法类必须回到官方系统截图或记录文号；口碑类至少要两个独立来源。 |
| 标注可访问性 | 记录时写明「检索日期＋入口＋关键词」，方便复核。抓不到正文的，写「搜索摘要显示」而不是「页面显示」。 |
| 区分身份 | 🎓 应届生优先校园渠道（就业网、校招网、内推）；💼 社招优先社会渠道（猎头、脉脉、猎聘）。两套渠道的数据不可互相外推。 |

### 3.1 水军与失真识别清单（口碑数据的强制前置检查）

| 信号 | 具体表现 | 处理方式 |
| --- | --- | --- |
| 时间集中 | 大量好评集中在同一周（常伴随招聘旺季或公关投放） | 视为投放，只保留差评线索 |
| 模板化措辞 | “扁平化管理”“leader 技术强”“福利拉满”反复出现，无具体事件 | 不计入口碑结论 |
| 无细节的极端评分 | 只有五星或一星，没有任何流程、时间、岗位描述 | 剔除 |
| 利益相关 | 帖子末尾挂内推码、课程、“帮你改简历” | 直接剔除，并反向标记为招聘营销 |
| 样本量 | 单一公司点评数 <10 条 | 只能写“样本过少，仅供参考”，不做星级化总结 |
| 平台不对称 | 只有某一家平台口碑极好，其他平台无信息 | 以“多平台一致”为采信门槛 |

| 数据类型 | 能否直接写入 | 写法要求 |
