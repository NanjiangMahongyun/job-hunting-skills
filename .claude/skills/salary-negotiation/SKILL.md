# Salary Negotiation (国内本土化谈薪)

## 适用场景

- 用户拿到offer，需要谈薪资
- 用户面试中被HR问期望薪资，不知道怎么答
- 用户收到口头offer，想确认哪些必须写进合同
- 用户提到"谈薪"、"砍价"、"HR问我要多少"、"这个offer值不值"
- 用户同时有多个offer，需要比价
- 配套使用：先跑 `company-due-diligence` 拿到公司风险，再跑本skill制定谈判策略

**参考依据**（两份知识库只作判断依据，本 skill 不复制其内容）：

- 报价折算口径 → `knowledge-base/五险一金与个税实操手册.md`：第二步拆解薪酬包、三档定价法（Know Your Number）与第六步 offer 校验时，用它把月薪折算成总包与到手，**重点问清缴费基数**（按最低基数交 = 隐性降薪），并核公积金比例与专项附加扣除。
- 面试期口径一致性 → `knowledge-base/面试高频问题与作答框架.md` 3.2「期望薪资是多少」：本 skill 与它同口径——HR 在面试里问期望薪资时的反问结构/报区间/换维度兜底话术，必须与后续谈薪报出的数字一致，不能面试报一套、offer 阶段报另一套。

## 最高优先级原则

1. **不编造薪资数据**：所有市场价参考必须基于搜索结果或用户提供的真实样本，没有数据就说"需要进一步调研"
2. **区分"口头承诺"和"书面offer"**：所有没写进offer/劳动合同的福利，一律视为不存在
3. **小微企业优先保现金，不画饼**：针对自然人独资/项目制公司，谈判优先级：基本工资 > 社保公积金基数 > 固定补贴 > 年终奖/绩效/项目奖
4. **基于风险定策略**：高风险公司（欠税/项目单一/口碑差），优先锁定底薪和发放稳定性，放弃对奖金的幻想

## 执行流程

### 第0步（前置）：确认求职身份（大学生 / 社会人员）

在制定谈判方案前，**先向用户确认求职身份**，两种身份的定价锚和薪酬包侧重完全不同：

**🎓 大学生 / 应届生（校招、实习通道）**
- **定价锚 = 行业起薪 + 城市应届生补贴**
  - 对标口径用**校招起薪/实习日薪**，不用社招月薪
  - 城市应届生政策计入收入：**生活补贴、租房补贴、落户**（补贴是一次性还是按月、申领条件）
  - **薪酬包看培养与户口**：带教/转正机制、能否落户（户口指标价值需折算进报价）
  - 警惕：HR 用"应届生统一定薪、没有谈的空间"挡掉谈判——真正常量是补贴与户口，不是底薪

**💼 社会人员 / 在职跳槽（社招通道）**
- **定价锚 = 当前薪资流水 + 期望涨幅 15–30%**
  - 先算清**现薪总包**（流水为准，含年终/绩效/补贴），报价 = 现薪 ×(1+涨幅)
  - **薪酬包看职级、签字费、期权、绩效保底**：定级直接决定后续涨薪斜率；签字费补跳槽损失；期权要看行权价与成熟期；绩效必须问保底比例
  - 警惕：平薪跳或只涨薪不升职 = 亏；公司用"应届生/低职级标准"压经验价值

**判定规则**：优先直接问用户；用户自述优先于简历/流水的任何推断，简历只作证据；无法确定时默认"🎓 大学生"分支，并在报告顶部标注「身份待确认」。确认后，第三档定价（Know Your Number）与话术按对应身份分支生成。

### 第一步：收集输入要素

在开始制定谈判方案前，必须先确认以下信息是否齐全：

**必填输入：**

1. 公司基本情况（如果已跑过 company-due-diligence，直接引用）
   - 公司规模、行业、业务模式
   - 风险等级（🔴/🟡/🟢）
2. 岗位信息
   - 岗位名称、工作内容、技术栈
   - JD里写的薪资范围
3. 用户自身情况
   - 当前薪资（如有）
   - 工作年限、核心技能、项目亮点
   - 其他offer（如有）
4. 求职身份（🎓 大学生/应届生 还是 💼 社会人员，第0步（前置）已确认）
   - 🎓 → 定价锚用行业起薪 + 城市应届生补贴，薪酬包看培养/户口
   - 💼 → 定价锚用当前薪资流水 + 期望涨幅 15–30%，薪酬包看职级/签字费/期权/绩效保底

**可选输入：**

- HR给出的口头薪资数字
- 书面offer全文
- 公司福利清单

**如果信息缺失：** 先向用户询问，不要基于假设制定谈判方案。

### 第二步：薪酬包完整拆解（国内版）

很多人只谈基本工资，忽略了隐性收入和风险项。必须逐项拆解：

| 项目            | 说明                       | 风险等级标识                      |
| ------------- | ------------------------ | --------------------------- |
| **基本工资（月）**   | 固定发放，不挂绩效                | 🟢 最核心，必须优先谈                |
| **绩效工资（月/季）** | 占月薪比例、考核标准、发放条件          | 🟡 问清楚：保底多少？考核指标是什么？        |
| **年终奖**       | 几个月？写不写进offer？挂不挂公司业绩？   | 🔴 口头承诺的年终奖=没有，必须写进offer才算数 |
| **项目奖/提成**    | 回款挂钩？项目周期？发放节点？          | 🔴 小微企业项目奖最容易画饼，大概率拿不到      |
| **社保公积金**     | 缴纳基数（按实际工资还是最低基数？）、公积金比例 | 🟡 按最低基数交=隐性降薪，江苏 2026 年度缴费工资基数下限 5025 元（上限 25127 元） |
| **试用期**       | 几个月？工资打几折？转正标准？          | 🟡 试用期工资不得低于80%，超过3个月要警惕    |
| **补贴**        | 餐补/交通补/住房补/通讯补？固定还是凭票？   | 🟡 问清楚：是不是永久的？会不会说取消就取消？    |
| **加班费/调休**    | 加班频率？有没有加班费？调休能不能休完？     | 🔴 大小周/996但没加班费=时薪大幅下降      |
| **年假/病假**     | 年假几天？带薪还是无薪？             | 🟢 法定最低5天，高于法定的都是福利         |

### 第二步附：Offer 综合评估（4 维度，改写自 [awesome-copilot / technical-job-search](https://github.com/github/awesome-copilot/blob/main/skills/technical-job-search/SKILL.md) 的 offer evaluation，MIT）

拿到offer后，不要只看薪资数字，从4个维度综合评估：

#### 维度1：薪酬（Compensation）
| 项目 | 评估要点 |
|------|---------|
| 基本工资 | 对标市场价（levels.fyi/职友集/脉脉/Glassdoor），看同岗位同级别同城 |
| 绩效/奖金 | 目标比例 vs 历史实际发放比例，问"去年发了多少" |
| 年终奖 | 几个月？写不写进offer？挂不挂公司业绩？ |
| 总包 | base + 预期奖金 + 年化股权/期权价值 |
| 时薪 | 月薪 ÷ 实际工作小时数，996的15K可能不如965的12K |

#### 维度2：岗位清晰度（Role Clarity）
| 项目 | 评估要点 |
|------|---------|
| 职责范围 | "负责"到底是什么意思？是已经定好的还是要自己摸索？ |
| 团队 | 多少人？什么结构？汇报给谁？团队平均司龄？ |
| 成长空间 | 下一级是什么？一般多久能晋升？有没有明确的晋升标准？ |
| 技术栈 | 用什么技术？是主流还是老旧？能不能写进简历？ |

#### 维度3：公司健康度（Company Health）
| 项目 | 评估要点 |
|------|---------|
| 经营状况 | 营收/融资/现金流，创业公司问"还能烧多久" |
| 工程文化 | PR review流程？线上事故复盘文化？值班压力？ |
| 人员流动 | 脉脉/职友集上的离职率，面试时问"团队最近有人离职吗" |
| 远程/混合 | 书面政策 vs 实际执行，很多公司写着弹性实际996 |

#### 维度4：红旗信号（Red Flags）
| 信号 | 风险 |
|------|------|
| 逼你48小时内决定 | 正常应该给1-2周考虑，急着签一定有问题 |
| 股权/期权没有明确变现路径 | 公司成立10年以上还没上市/被收购，期权=废纸 |
| 说是"新项目/从0到1"，实际有6个月没人维护的烂代码 | 接盘侠 |
| HR回避具体数字 | 问薪资说"看能力"，问奖金说"看表现"=大概率低 |
| 面试流程混乱/面试官态度差 | 进去后工作体验也好不了 |

> **原则**：所有东西都要写进书面offer再接受。口头承诺=没有。

### 第三步：市场价对标

**必须联网搜索，不能凭感觉给数字。**  
搜索关键词模板：

- "[城市] [岗位] [工作年限] 薪资"
- "[公司名] 薪资 职友集"
- "[城市] IT 开发 薪资水平 2025"
- "南京 Java 开发 3年 工资"

**输出要求：**

- 给出25分位/50分位/75分位区间，标注数据来源
- 明确告诉用户：这个公司属于什么水平
- 如果搜不到该公司的具体数据，标注"无公开数据，基于行业平均估算"

### 第三步附：Know Your Number（三档定价法：底线 / 目标 / 要价）

> 三档定价（reservation price → target → anchor）是谈判学的通用做法，本包按国内薪资结构落地；类似思路也可参考 [jennifer88huang/interview-skills](https://github.com/jennifer88huang/interview-skills)（MIT，含 salary negotiation skill）。**分位数值（25/50/75）必须来自第三步的市场价检索结果，不得凭感觉填。**

谈薪前必须明确自己的三个数字，不要临场拍脑袋：

| 档位 | 定义 | 怎么定 |
|------|------|--------|
| **底线（Minimum）** | 低于这个数直接拒绝，不犹豫 | 覆盖生活成本 + 市场价25分位 + 你的最低接受度 |
| **目标（Target）** | 拿到这个数就满意，开心接受 | 市场价50分位，结合你的优势和公司劣势上浮 |
| **要价（Ask）** | 谈判时第一次报的数，留出让步空间 | 市场价75分位，比目标高10-15% |

**示例：**
- 底线：8K（低于这个活不下去/不如别家）
- 目标：10K（市场价中位数，满意）
- 要价：11.5K（报出去，HR砍到10K正好）

**使用方法：**
1. HR问期望薪资时，报"要价"（11.5K），不要报"目标"
2. HR压价时，逐步让步，但绝不低于"底线"（8K）
3. 如果HR直接给了"目标"以上，不要表现得太惊喜，淡定接受或再小幅争取
4. 多个offer时，每个offer分别算三档，横向对比

### 第四步：制定谈判策略

**根据公司风险等级调整谈判优先级：**

#### 🔴 高风险公司（欠税/项目单一/口碑差/规模<20人）

**谈判优先级：**

1. 基本工资尽量往高了谈（哪怕年终奖画饼也不要降底薪换年终奖）
2. 社保公积金必须按实际基数交（这是硬保障）
3. 试用期工资不低于80%，试用期不超过3个月
4. 所有口头承诺必须写进offer
5. 放弃对年终奖、项目奖的期待，按"只有基本工资"做决策

**谈判话术倾向：**

- "我理解公司有业绩要求，但我更希望在保障稳定的基础上再谈绩效"
- "社保按实际基数缴纳是我的底线"

#### 🟡 中风险公司（有历史风险但已结清/规模20-50人/业务稳定但行业单一）

**谈判优先级：**

1. 基本工资 + 固定补贴
2. 社保公积金基数
3. 年终奖写进offer（哪怕只有1-2个月）
4. 项目奖可以谈，但不要抱太高期待

#### 🟢 低风险公司（成立5年+/规模稳定/口碑正面/无重大风险）

**谈判优先级：**

1. 总包（base + 年终奖 + 福利）
2. 成长空间、晋升路径
3. 年假、加班政策等软性福利

### 第五步：分场景话术库

#### 场景1：面试中HR问"你的期望薪资是多少？"

**原则：不要先报具体数字，先问对方预算范围。**

**话术A（对方没写薪资范围时）：**

> "我对这个岗位很感兴趣，想先了解一下公司这个岗位的薪资预算范围大概是多少？这样我也能判断双方是否匹配。"

**话术B（必须说一个数字时）：**

> 报一个比你预期高20-30%的数字，留出让步空间。  
> 例如你期望8K，就说"我期望在10-12K左右"。  
> **注意：不要报太低，报低了之后很难涨回去。**

**话术C（对方说"你之前工资多少？"）：**

> "我之前的综合薪资是X（如实说基本工资，不要把奖金算进去），考虑到岗位内容和公司情况，我期望能有X-X的涨幅。"

---

#### 场景2：HR压价"这已经是我们能给的最高了"

**拆解：先问清楚"最高"指的是什么。**

**话术：**

> "我想确认一下，这个'最高'是指基本工资，还是包含了绩效和补贴的总包？如果是基本工资的话，我觉得还有一些协商空间。"
>
> "我理解公司有薪资带宽，那请问这个带宽的上限是多少？我希望能尽量接近上限。"

**让步策略（不要一次让到底）：**

- 第一次还价：在对方基础上+15-20%
- 对方拒绝后：退到+10%
- 最后底线：+5% 或者 用其他福利补（比如多一天年假、更高的公积金比例、签字费）

---

#### 场景3：HR画饼"年终奖有3-6个月，项目奖很多"

**原则：所有口头画饼，一律要求写进offer。**

**话术：**

> "我理解年终奖是和公司业绩挂钩的，那想请问一下，过去两年公司实际发放的年终奖平均是几个月？这个会写在offer里吗？"
>
> "项目奖的话，想了解一下发放的具体条件和节点？比如项目验收后多久发？按回款比例还是固定比例？"

**如果对方说"这个是公司惯例，不会写进offer"：**

> 你心里就要打个折：口头说6个月年终奖，实际能拿到1-2个月就不错了。决策时按"没有年终奖"算总包。

---

#### 场景4：想争取更高薪资但怕把人吓跑

**原则：表达强烈兴趣，同时提合理要求。**

**话术：**

> "我对这个岗位和公司都很认可，也很希望能加入。关于薪资，我目前的考虑是X-X，主要是基于我的X年经验和X项目经历。如果这个数字有困难，我们也可以看看其他方面能不能调整，比如试用期长度、补贴、年假之类的。"

---

### 第六步：offer校验清单（收到书面offer后逐项核对）

**以下内容必须全部出现在书面offer或劳动合同里，缺一个就问：**

- [ ] 基本工资：多少？发放日？
- [ ] 绩效工资：占比？考核标准？保底多少？
- [ ] 试用期：几个月？工资多少？转正条件？
- [ ] 社保：缴纳基数？从什么时候开始交？
- [ ] 公积金：基数？比例？
- [ ] 年终奖：几个月？发放时间？（如果写了才算数）
- [ ] 补贴：哪些？多少钱？是不是固定？
- [ ] 工作时间：朝九晚五？大小周？加班怎么算？
- [ ] 年假：几天？
- [ ] 岗位职责：和面试说的是不是一致？

**任何一项模糊不清，都要发邮件/微信找HR确认，保留聊天记录。**

## 角色扮演模式（对练）

用户说"我们来对练一下谈薪"时，进入此模式：

1. 我扮演HR，根据公司风险等级和岗位，提出典型的压价/画饼问题
2. 用户回答后，我给出反馈：哪里答得好、哪里可以改进、有没有踩坑
3. 连续练习3-5个常见场景，直到用户能熟练应对

**典型对练场景：**

1. "你的期望薪资是多少？"
2. "我们这个岗位预算就是X，不能再高了"
3. "年终奖我们一般发3-6个月，看个人表现"
4. "试用期3个月，工资打8折，没问题吧？"
5. "我们是大小周，平时偶尔加班，年轻人多锻炼锻炼"

## 禁止行为清单

1. ❌ 禁止编造薪资数据，没有搜索就说"需要进一步调研"
2. ❌ 禁止把口头承诺当成真实收入计算总包
3. ❌ 禁止鼓励用户为了高底薪盲目拒绝好机会（要综合看成长）
4. ❌ 禁止教用户撒谎（比如虚报当前薪资）
5. ❌ 禁止承诺"一定能谈到X K"，谈判结果取决于双方
