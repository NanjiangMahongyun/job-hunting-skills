# 主动离职与跳槽决策（该不该走 → 安全落地）

## 这个 skill 干什么

针对你当前的公司 + 你，做**主动离职与跳槽**的决策与执行：

1. **该不该走**：时机判断（公司经营/成长/薪资/上下级）
2. **跳槽时机**：窗口、拿年终/背书后再走
3. **主动离职步骤**：在职骑驴找马、提离职、交接、社保衔接、背调、竞业
4. **跳槽理由口径**：简历 + 面试 + 背调一致

**和现有 skill 的边界（引用但不重复写）：**
- 被辞退/被迫离职的补偿计算、劳动仲裁 → `.claude/skills/severance-calculator/SKILL.md`
- 离职交接/竞业/社保/背调细节 → `knowledge-base/离职与背调合规手册.md`
- 新 offer 的薪资谈判 → `knowledge-base/社招跳槽谈判指南.md`
- 跳去哪一类公司、类型间结构差异 → `knowledge-base/公司类型画像与选择指南.md`：第一、二步判完"该不该走"后，用它的 11 类 × 7 维度比较"留在原类型 vs 跳到目标类型"的签约主体、薪资结构骨架与稳定性得失，防止跳进外包后签约主体变了。
- 背调与目标公司核查入口 → `knowledge-base/求职信息渠道与数据源清单.md`：第三步"社保衔接/背调配合"用它确认背调方能查到什么、自己的自证材料去哪查；对候选目标公司按它的工商司法章开核查渠道，并依 ✅/⚠️/❌ 分级决定哪些结论能写进跳槽报告。
- 在岗期间的融入/留痕/风险监测 → `.claude/skills/onjob-management/SKILL.md`

**同类现状（已调研，2026-10）**：github 上成熟求职 skill 集中在"求职动作"段（JD/简历/面试/offer 评估），无"求职者主动离职/跳槽决策"的现成独立成熟 skill——本 skill 为差异化补位，内容为自建方法论，不复制任何第三方。

## 执行流程（必须按顺序）

### 第0步（前置）：确认求职身份（大学生 / 社会人员）

在判断该不该走前，**先向用户确认求职身份**，两种身份的跳槽结论完全不同：

**🎓 大学生 / 应届生（校招、实习通道）**
- **本 skill 的身份差异**：
  - **应届/入职第一年原则上慎重跳槽**：应届身份只有一次（校招通道、补贴、落户资格随离职失效），试用期短跳会留下"稳定性差"记录，直接压低下一份议价
  - 先分辨当前是**实习/试用/已转正**：实习期离开无劳动关系约束，试用期离开需提前 3 天；三方协议违约条款先核
  - 只有在"签约主体是外包/被毁约/无培养体系"时才建议早走，并说明理由

**💼 社会人员 / 在职跳槽（社招通道，本 skill 主场景）**
- **本 skill 的身份差异（必须逐项评估）**：
  - **涨幅**：跳一次至少 15–30%，平薪跳必须换来职级或赛道，否则不成立
  - **空窗期**：裸辞空窗对社招议价伤害大，默认在职骑驴找马
  - **背调连续性**：任职时间线是否连贯、每段能否提供证明人与劳动合同/社保对应
  - **社保断缴**：离职当月减员与新公司衔接、断缴对买房/落户/医保资格的城市性影响
  - **竞业限制**：离职前确认是否签过、范围与补偿，竞业期内目标公司是否在限制名单
  - **原单位交接期**：提前 30 天书面、交接记录留证、离职证明 15 日内必须拿到

**判定规则**：优先直接问用户；用户自述优先于简历/记忆的任何推断，简历与归档只作证据；无法确定时默认"🎓 大学生"分支，并在报告顶部标注「身份待确认」。确认后，第一至五步按对应身份分支执行（应届生走慎重评估，社会人员走六项必评）。

---

### 第0步附：确认当前处境（先问，不靠猜）

必须向用户确认：
- 身份：🎓 大学生/应届生 还是 💼 社会人员（第0步（前置）已确认，决定走哪条分支）
- 公司：名称 / 行业 / 规模 / 大致经营状况 / 岗位 / 直属上级
- 自己：在职时长 / 职级 / 薪资 / 核心诉求（为什么想走 / 想跳到什么方向）
- 用户对现状的一句话自述（触发想走的信号）

> 规则：先问用户处境，用户自述优先，不凭简历或猜测推断。

---

### 第一步：该不该走（时机判断）

| 该走的信号 | 可再等等 |
|-----------|---------|
| 公司经营恶化（欠薪/裁员） | 短期现金流好 + 有成长 |
| 职责架空 / 无成长 / 薪资倒挂严重 | 手上项目能背书，跳出去更值钱 |
| 频繁画饼不兑现 | 转正/晋升在即，拿到再走更划算 |
| 与上级/价值观严重冲突 | 骑驴找马找到更好再走 |

**关键原则**：**在职期间骑驴找马**永远优于裸辞——有收入底气，议价也更高（见社招谈判指南"在职vs离职"）。

---

### 第二步：跳槽时机与窗口
- 金三银四（3-4月）、金九银十（9-10月）岗位多、议价空间大
- 拿年终/绩效后再走更划算（卡在发放节点前别冲动）
- 转正/晋升拿到、项目收官拿到背书后再跳

---

### 第三步：主动离职步骤（在职跳槽）
1. **准备期（在职，保密）**：更新简历 → 找机会（内推/招聘）→ 面试（利用休息日/请假，保密）
2. **谈定 offer 后**：确认新 offer 薪资/定级/入职时间，再向现公司提离职
3. **提离职**：提前 30 天书面（试用期提前 3 天），邮件/EMS 留证
4. **交接**：按流程交接、归还物品、留交接记录；不恶语相向（圈子小，留好名声）
5. **离职证明**：公司 15 日内必须开；内容有误要求更正
6. **社保衔接**：离职当月确认减员，新公司入职衔接，避免断缴（见离职与背调手册）
7. **背调配合**：预留可配合的前同事/上级联系人；跳槽理由口径统一（职业发展，不贬低上家）
8. **竞业核实**：离职前确认是否签过竞业协议及条款（见离职与背调手册）

---

### 第四步：跳槽理由口径（简历 + 面试 + 背调一致）
- 正面：职业发展 / 技术方向升级 / 平台成长 / 职级晋升
- 避免：钱少事多、领导差、被裁（除非被问，策略性正面化）

## 禁止行为

1. ❌ 不编造公司经营/风险事实——只基于用户提供的信号和可查信息分析
2. ❌ 不重复写 离职手册/05/社招谈判指南 已覆盖的内容——本 skill 只做"跳槽决策与执行"的整合
3. ❌ 不建议为跳槽而跳槽——时机判断基于事实信号，不制造焦虑
4. ❌ 不教用户在职期间消极怠工或恶意隐瞒——在职求职要保密但职业诚信不能丢
5. ❌ 不承诺"一定能走成/一定能涨薪"——跳槽结果取决于市场与自身条件
