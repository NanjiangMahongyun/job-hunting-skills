# 行业背景分析（根据简历自动搜集行业资料）

## 这个 skill 干什么

用户想了解目标行业的最新情况时，根据用户简历（或指定的行业/岗位），联网搜索：
- 行业最新动态和新闻
- 发展趋势和技术方向
- 就业市场数据（招聘量、薪资、竞争程度）
- 高校相关专业报名/毕业情况（供给端）
- 政策影响（监管、补贴、限制）
- 头部公司动态

输出一份行业背景报告，帮助用户判断：这个行业值不值得进、现在是风口还是下坡、竞争激烈不激烈、薪资趋势如何。

**参考依据**：

- 行业数据与薪资来源 → `knowledge-base/求职信息渠道与数据源清单.md`：第二步 C 就业市场数据、E 政策影响以及报告里的薪资分位，从它的"行业与政策数据""薪资行情"两章开渠道（统计局/部委/地方政府原文、上市公司披露、官方工资价位分位），替代随手引用的自媒体；"信息可信度说明"一节按其 ✅/⚠️/❌ 分级落笔。

## 执行流程

### 第0步（前置）：确认求职身份（大学生 / 社会人员）

在确定分析对象前，**先向用户确认求职身份**，同一行业对两种身份的供给与结论完全不同：

**🎓 大学生 / 应届生（校招、实习通道）**
- **本 skill 的身份差异（只查这些口径）**：
  - **校招岗位供给**（校招名额总量、开放岗位方向、是否收缩）
  - **对口专业设置与报名/就业数据**（专业点数量、报名人数增减、就业率与毕业生规模 = 未来1-3年供给）
  - **起薪区间**（校招定薪档位、实习日薪，不用社招月薪混用）
  - **头部公司校招规模**（哪几家在扩校招、哪几家砍了名额）

**💼 社会人员 / 在职跳槽（社招通道）**
- **本 skill 的身份差异（只查这些口径）**：
  - **社招岗位量与跳槽涨幅**（社招在招数、经验年限要求、该方向实际跳槽涨幅是否仍有 15-30%）
  - **该行业裁员与扩编动态**（近6-12个月裁员/组织架构调整 vs 新业务扩编）
  - **目标职级供需**（初/中/高/专家各级候选人供给与公司需求比，高级别是否更稀缺）
  - **哪些公司是这个方向的梯队头部**（第一梯队/第二梯队、社招口碑与稳定性）

**判定规则**：优先直接问用户；用户自述优先于简历/历史记录的任何推断，简历只作证据；无法确定时默认"🎓 大学生"分支，并在报告顶部标注「身份待确认」。确认后，第二步搜索关键词与第六步建议按对应身份分支输出。

---

### 第一步：确定分析对象

**优先向用户确认（不得只从简历推断）：**
- **求职身份**：🎓 大学生/应届生 还是 💼 社会人员（第0步（前置）已确认，决定看校招供给还是社招供需）
- **求职方向**：目标行业/岗位（如"AI Agent / RAG 大模型应用"、"Java 后端"、"软件测试"）
- **自我定位/自述**：用户如何描述自己的优势和定位（如"主力 AI Agent，Java 只是工具"、"有 Agent 后重决策"）
- **目标地区**：如"南京"、"长三角"（影响就业数据）

再从用户输入/简历中提取作为补充：
- **用户背景**：专业、技能、经验（影响匹配度分析）

**为什么必须先问**：简历可能滞后于用户当下的求职方向（如简历以 Java 后端为主，但用户真实主力是 AI Agent），只从简历推断会分析错行业。**用户自述优先级高于简历推断**。

如果用户没有明确方向，才结合简历推断，但必须标注"基于简历推断，建议用户确认"。

---

### 第二步：联网搜索（必须实际搜索，禁止编造）

按以下维度搜索，每个维度至少搜1-2个关键词：

**A. 行业最新动态（近3-6个月）**
- 搜索："[行业] 2026 最新动态"、"[行业] 新闻"、"[行业] 政策"
- 提取：重大事件、政策变化、技术突破、头部公司动向

**B. 发展趋势**
- 搜索："[行业] 发展趋势 2026"、"[行业] 未来3年"、"[技术] 行业报告"
- 提取：增长/衰退信号、技术方向、新兴细分领域、被淘汰的方向

**C. 就业市场数据**
- 搜索："[岗位] 招聘需求 2026"、"[行业] 就业形势"、"[岗位] 薪资 南京"
- 提取：招聘量变化、薪资区间、竞争激烈程度、热门城市
- 参考：BOSS直聘/拉勾/猎聘的招聘数据、智联招聘/前程无忧的就业报告

**D. 高校专业供给**
- 搜索："[专业] 报名人数 2026"、"[专业] 就业率"、"[专业] 毕业生人数"
- 提取：专业热度变化（报名人数增/减）、毕业生规模、就业率
- 注意：这决定了未来1-3年的竞争供给

**E. 政策影响**
- 搜索："[行业] 政策 2026"、"[行业] 监管"、"[行业] 补贴"
- 提取：利好政策（补贴、税收优惠）、利空政策（监管、限制）

**F. 头部公司动态**
- 搜索："[行业] 头部公司 裁员/招聘/融资"
- 提取：大厂在扩招还是裁员、融资情况、业务方向调整

---

### 第三步：综合分析

把搜索到的信息整理成分析框架：

**行业生命周期判断：**
| 阶段 | 特征 | 求职建议 |
|------|------|---------|
| 风口期 | 融资多、招聘旺、薪资涨、新人涌入 | 积极进入，薪资有议价空间 |
| 成熟期 | 增长平稳、招聘稳定、竞争激烈 | 可以进，但要差异化竞争 |
| 衰退期 | 裁员多、融资少、薪资停滞 | 谨慎进入，考虑转型 |
| 政策驱动期 | 政策利好/利空明显 | 看政策持续性，短期机会 vs 长期风险 |

**供需分析：**
- 需求端：企业招聘量在增还是减
- 供给端：毕业生/转行者在增还是减
- 供需比决定了议价权：需求>供给 = 你有筹码；供给>需求 = 公司有筹码

**薪资趋势：**
- 当前薪资区间
- 同比变化（涨了还是跌了）
- 不同经验段的薪资差异

## 常见行业分析要点（参考框架）

### AI/大模型行业
- 关注：大模型公司融资/裁员、算力成本、应用落地情况、政策监管（生成式AI管理办法）
- 供给端：计算机/AI专业报名暴增，培训产出大量转行者
- 风险：泡沫化、技术迭代快、基础岗被AI替代

### 传统软件开发（Java/前端/测试）
- 关注：企业数字化投入、外包行业变化、低代码/AI对基础岗的替代
- 供给端：计算机专业毕业生基数大，培训产出多
- 趋势：中端岗位竞争激烈，高端/行业专家稀缺

### 新能源/智能汽车
- 关注：销量数据、价格战、车企裁员/扩招、智能化投入
- 政策：新能源补贴退坡、双积分政策
- 机会：智能化（自动驾驶、座舱）需求大，传统机械岗收缩

### 政企/信创
- 关注：政府采购、国产化替代、信创目录
- 特点：项目制、稳定、薪资中等、对学历/背景有要求
- 风险：依赖政府预算，项目回款慢

## 禁止行为

1. ❌ 禁止编造行业数据，所有数字必须来自搜索结果并标注来源
2. ❌ 禁止说"这个行业肯定有前途/肯定不行"，只给事实+基于事实的分析
3. ❌ 禁止把"未查到"说成"没有"
4. ❌ 禁止预测未来，只说"基于当前数据，趋势是……"
5. ❌ 禁止忽略用户简历背景，分析必须结合用户的专业/技能/经验
