# 补偿金计算与维权（被辞退/想走时用）

## 这个 skill 干什么

用户被辞退、被劝退、或想主动离职时，输入基本信息，我：
1. 自动计算 N / N+1 / 2N 具体金额
2. 判断公司的说法/操作是否合法
3. 给出应对话术和操作步骤
4. 列出需要留存的证据清单
5. 提供劳动仲裁全流程指引

**所有计算和判断依据 `knowledge-base/毕业常识完整版.md` 第六、七部分。**

- 社保断缴与基数连带影响 → `knowledge-base/五险一金与个税实操手册.md`：第二步算 N 的月工资基数、第五步与"社招专属维权场景"处理断缴/补缴时用它——查实际缴费基数、算清断缴与公积金转移接续的后果；违法定性、被迫解除与仲裁投诉路径一律仍回《毕业常识完整版》第七部分。
- 违法情形与维权条款定位 → `knowledge-base/法律知识快速索引.md`：第三步"公司有哪些违法情形"（未缴社保、拖欠工资、未签劳动合同、违法解除）和第四步取证、第六步仲裁流程，先用索引表查到对应的《毕业常识完整版》章节号再展开，避免漏项或引错条。

## 执行流程

### 第0步（前置）：确认求职身份（大学生 / 社会人员）

**🎓 大学生 / 应届生**：多为实习期纠纷（实习协议、试用期）；补偿场景少，重点在试用期辞退、三方违约。

**💼 社会人员 / 在职（本 skill 主要适用）**
- 补偿金计算（N/N+1/2N）对所有在职人员适用
- **社招专属补充场景**：裁员（经济性裁员 N）、协商解除、违法解除、**竞业限制**（离职后竞业补偿）、社保断缴/补缴、背调风险、离职交接、竞业违约金
- 工作年限越长，N 基数越大，封顶规则（3倍社平、12年上限）需重点核算

**判定规则**：优先问用户；若为社会人员，进入流程后额外核查「社招维权场景」小节（竞业/社保/背调），应届生可跳过该小节。

---

### 第一步：收集输入

必须确认以下信息：

| 信息 | 为什么需要 |
|------|-----------|
| 入职日期、离职日期 | 算工作年限（N的基数） |
| 月工资（税前，含奖金津贴） | 算补偿金额 |
| 离职原因（公司辞退/协商/主动辞职/合同到期） | 决定有没有补偿 |
| 公司有没有提前30天通知 | 决定有没有+1（代通知金） |
| 公司给出的解除理由 | 判断是否合法解除 |
| 有没有签书面文件 | 判断证据是否充分 |
| 试用期还是已转正 | 影响补偿计算 |

---

### 第二步：计算补偿金

**N 的计算（知识库第三十五节）：**
- 每满1年 → 1个月工资
- 6个月以上不满1年 → 按1年算
- 不满6个月 → 半个月工资
- 月工资 = 解除前12个月平均应得工资（税前，含全部货币性收入）

**三种类型判断：**

| 类型 | 适用情形 | 金额 |
|------|---------|------|
| **N（经济补偿）** | 协商解除（公司提出）、无过失辞退、经济性裁员、合同到期公司不续签、被迫解除 | 工作年限 × 月工资 |
| **N+1** | 仅限第40条三种情形（医疗期满不能工作、不胜任经培训仍不胜任、客观情况重大变化）且未提前30天通知 | N + 1个月工资 |
| **2N（赔偿金）** | 违法解除/终止（无正当理由、程序违法、辞退孕期/医疗期员工） | 2 × N |

**应届生常见场景速算：**

| 场景 | 工作时间 | 补偿 |
|------|---------|------|
| 入职3个月被无理由辞退 | 不满6个月 | 0.5个月工资（违法解除则1个月） |
| 入职8个月被协商解除 | 6个月以上 | 1个月工资 |
| 入职1年2个月被无过失辞退 | 1年以上 | 1.5个月工资 + 未提前通知则+1 |
| 试用期以"不符合录用条件"辞退但无书面标准 | — | 违法解除 → 2N（0.5×2=1个月） |

> 南京社平工资约 13759 元/月、3 倍封顶约 41277 元/月（**待核实**：以南京市人社局/江苏省统计局当年公布的"上年度职工月平均工资"为准，可拨 025-12333 复核）。应届生薪资远低于此，**无需担心封顶**。

---

### 第三步：判断公司操作是否合法

**公司最爱用的套路和反制（知识库第三十七节）：**

| 公司说/做 | 真相 | 你的应对 |
|-----------|------|---------|
| "你自己写辞职信吧，好聚好散" | 主动辞职 = 0补偿 | 绝不写。"请出具书面解除通知" |
| "试用期不符合录用条件" | 必须有入职时书面确认的客观标准 | 要求出示书面录用条件+考核证据，无则违法解除主张2N |
| "严重违反公司制度" | 制度必须经民主程序制定并公示 | 要求出示公示证据，未经公示不能作为解除依据 |
| "能力不行，不胜任" | 必须先培训或调岗，仍不胜任才能解除，且N+1 | 直接辞退=违法解除 |
| "公司困难，先签这个无争议协议" | 签了就放弃所有权利 | 不签。算清所有应付金额再谈 |
| "调岗到外地，不去算自动离职" | 变相辞退 | 调岗需协商一致，不同意就按正常流程 |
| "不接受就不给你开离职证明" | 拒开离职证明违反法定出具义务，可投诉并主张赔偿 | 留存证据（你自己参与的对话可录音），向劳动监察投诉 |

### 第五步：被迫解除路径（主动辞职也能拿钱）

如果公司存在以下情形，用户可以主动解除并主张 N（知识库第三十七节37.3）：
1. 未及时足额支付工资
2. 未依法缴纳社保
3. 规章制度违法损害权益
4. 以欺诈/胁迫订立合同

**操作顺序（不能错）：**
1. 先发书面《被迫解除劳动合同通知书》，列明具体违法事实和法律条款
2. EMS寄送并保留回执，同时邮件/企业微信发一份
3. 办理交接，索要离职证明
4. 申请劳动仲裁主张经济补偿

> 🚨 **注意**：必须先发通知再走人。先写"个人原因辞职"再想主张就非常被动了。

## 劳动仲裁速查（知识库第三十九节）

| 项目 | 内容 |
|------|------|
| 管辖 | 劳动合同履行地 或 用人单位所在地仲裁委 |
| 时效 | 一般1年；欠薪在职不受限，离职后1年内 |
| 费用 | **免费** |
| 审结 | 受理后45天，复杂可延15天 |
| 一裁终局 | 欠薪/补偿 ≤ 31920元（南京最低工资×12），公司不能起诉 |

## 社招专属维权场景（社会人员补充）

### 竞业限制（离职后）
- 竞业协议：离职后遵守竞业，公司**必须按月支付竞业经济补偿**（通常离职前 12 个月平均工资的 30%），未支付则可主张解除竞业义务
- 竞业期限最长 2 年；范围过宽可主张不合理
- 离职前先核实是否签过竞业协议及条款

### 社保断缴 / 补缴
- 跳槽空窗导致社保断缴：影响医保连续、买房/落户资格
- 可主张：新公司入职即参保；断缴部分按当地政策补缴
- 未依法缴纳社保 = 可被迫解除主张 N（见第五步）

### 背调风险
- 背调会查：学历、工作经历、离职原因、薪资流水
- 求职如实但策略性表述（跳槽理由正面化），不造假
- 被恶意背调/上家负面评价：留存证据，必要时申诉

### 裁员（经济性裁员）
- 裁员 = 经济补偿 N（需提前 30 天或支付 +1）——注意裁员名单/程序是否合法，违法裁员可主张 2N
- 裁员谈判：争取 N+ 额外补偿包（N+1 到 2N 之间可谈），签约前算清全部

### 工作年限长时（封顶规则重点）
- N 封顶：月工资 3 倍社平封顶 + 年限 12 年封顶
- 南京社平约 13759 元/月，3 倍封顶约 41277 元/月（**待核实，以当年官方公布为准**）——高薪/长年限需重点核算

## 禁止行为

1. ❌ 禁止算错数字，必须展示计算过程
2. ❌ 禁止鼓励用户情绪化裸辞
3. ❌ 禁止说"肯定能拿到X元"，仲裁结果取决于证据
4. ❌ 禁止编造法律条文，所有依据来自知识库
5. ❌ 禁止建议用户销毁证据或伪造证据
