# Company Due Diligence (求职向公司尽调)

## 适用场景
- 用户拿到多个offer，需要横向对比公司
- 用户准备入职某家公司，想了解风险
- 用户提到"这家公司靠谱吗"、"对比一下这几家"、"有没有坑"
- 用户提供公司名称，要求评估经营稳定性/风险/口碑

**参考依据**（两份知识库只作判断依据，本 skill 不复制其内容）：

- 工商/司法/口碑入口与引用资格 → `knowledge-base/求职信息渠道与数据源清单.md`：第一步 A/B/C/D 各维度开源时按它的工商司法章与员工口碑章查（含付费/免费口径），报告里哪些能写成事实、哪些只能标为"未经核实"，一律按它的 ✅ 事实级 / ⚠️ 只作线索 / ❌ 不得写入 分级判。
- 先定类型再叠加专属项 → `knowledge-base/公司类型画像与选择指南.md`：第一步先判目标公司属 11 类中的哪一类（大厂/国企央企/事业单位/人力外包/项目外包/研究院所/外企研发中心/银行金融科技…），再叠加该类专属的"尽调重点"与"红旗"，而不是所有公司套同一张核查表。

## 最高优先级铁律（绝对不能违反）
1. **禁止编造任何数据**：所有工商信息、司法案件、风险记录、口碑评价，必须来自实际搜索结果
2. **搜不到就明确说"未查到"**：绝对不能用"一般来说"、"通常"、"大概"来填充缺失数据
3. **每条关键信息必须标注来源**：搜索结果里没有的，一律不写
4. **区分"已查证"和"传闻/单方说法"**：口碑类信息要标注来源平台（脉脉/职友集/知乎）
5. **不主观臆断**：只陈述事实+基于事实的风险推演，不直接下"这家公司是骗子"这种结论

## 执行流程（必须按顺序）

### 第0步（前置）：确认求职身份（大学生 / 社会人员）

在开始任何检索前，**先向用户确认求职身份**，不同身份要查的风险项完全不同：

**🎓 大学生 / 应届生（校招、实习通道）**
- 关注点是"这家公司会不会坑学生"
- **本 skill 的身份差异（重点核查项）**：
  - 是否有校招/实习**培养体系**（带教机制、转正通道、实习留用率）
  - **签约主体是否为外包或第三方人力公司**（合同主体 ≠ 实际用工单位 → 派遣/外包红旗）
  - 是否**拖欠实习生报酬**（搜"[公司] 实习生 工资 拖欠"）
  - 有无被曝光的**校招毁约/砍offer**记录（搜"[公司] 校招 毁约"）

**💼 社会人员 / 在职跳槽（社招通道）**
- 关注点是"进去后权益能不能保住"
- **本 skill 的身份差异（重点核查项）**：
  - **背调是否第三方执行**（第三方机构 → 核授权边界、离职原因口径）
  - **社保实缴人数与基数**（参保人数 vs 宣称规模、是否按最低基数缴）
  - **竞业限制使用是否泛滥**（普通开发/测试岗也要求签竞业 = 制度性风险）
  - **劳动仲裁与欠税记录**（开庭公告案由含劳动争议、欠税公告）
  - **近一年裁员或经营异常**（裁员新闻、经营异常名录、突然大规模缩招）

**判定规则**：优先直接问用户；用户自述优先于简历/历史记录的任何推断，简历与记忆只作证据补充；无法确定时默认"🎓 大学生"分支，并在报告顶部标注「身份待确认」。确认后，后续检索关键词与风险评级权重按对应身份分支执行。

---

### 第0步附：确认数据获取方式（是否有付费 API，必问）

在开始任何检索前，**先向用户询问**是否有企查查/天眼查等工商、司法数据平台的付费调用能力：

1. **询问是否有 API Key / 付费账号**：例如"是否有企查查或天眼查的 API Key？"
2. **若有**：保留并使用该平台的**付费 API 调用**，直接获取更精确的结构化数据（精确参保人数、注册资本/实缴、完整司法案件清单、欠税、经营异常等），写入尽调报告。
3. **若没有 / 用户未提供**：启用默认**免费版**——用通用搜索（general_search）检索企查查/天眼查/国家企业信用信息公示系统/中国执行信息公开网/信用中国等**公开页面**，从搜索结果中提取信息。

**规则：**
- 用户明确提供 API Key 时才走付费通道；**绝不假设用户有 key**，更不凭空编造付费接口返回的数据。
- 免费版无法覆盖的字段（如精确参保人数、完整司法案件清单），如实写"未查到/公开渠道不全"，不编造。
- 无论付费还是免费，所有数据必须来自实际检索，禁止编造（沿用下方铁律）。
- 若用户既没提供 key 也没禁用付费，一律按默认免费版执行。

### 第一步：收集基础信息
对每家目标公司，必须搜索以下维度（使用 general_search 工具）：

**A. 工商基础信息（必查）**
- 搜索关键词："[公司全称] 企查查"、"[公司全称] 天眼查"
- 需要提取：
  - 成立时间、注册资本、实缴资本
  - 法定代表人、股东结构
  - 参保人数（判断真实规模）
  - 经营状态（存续/注销/吊销）
  - 注册地址

**B. 经营与司法风险（必查）**
- 搜索关键词："[公司全称] 被执行人"、"[公司全称] 失信"、"[公司全称] 欠税"、"[公司全称] 开庭公告"、"[公司全称] 行政处罚"
- 需要提取：
  - 是否被列入失信被执行人/限制高消费
  - 欠税记录（金额、所属期）
  - 司法案件数量、案由（劳动纠纷？合同纠纷？）
  - 行政处罚记录

**C. 业务模式与客户（必查）**
- 搜索关键词："[公司全称] 主营业务"、"[公司全称] 中标"、"[公司全称] 客户"
- 需要提取：
  - 是自研产品还是外包/项目制
  - 主要客户群体（政企/互联网/海外）
  - 是否高度依赖单一客户
  - 最近中标项目（判断业务活跃度）

**D. 员工口碑与职场评价（选查但尽量查）**
- 搜索关键词："[公司全称] 怎么样 加班"、"[公司全称] 脉脉"、"[公司全称] 职友集"、"[公司全称] 面试经验"
- 需要提取：
  - 加班情况（大小周？996？）
  - 薪资发放是否及时
  - 人员流动率（从招聘信息频繁度判断）
  - 负面评价集中点（社保？绩效？管理层？）

### 第二步：风险评级
对每家公司，基于查到的事实给出风险等级：

| 风险等级 | 判定标准（满足任一） |
|---------|-------------------|
| 🔴 高风险 | 失信被执行人/欠税大额/经营异常/参保人数<10且成立超3年/大量劳动纠纷 |
| 🟡 中风险 | 有司法案件但已结案/历史欠税已结清/规模小但业务稳定/口碑两极分化 |
| 🟢 低风险 | 成立5年以上/参保人数稳定/无重大风险记录/口碑整体正面 |

**注意**：评级必须基于查到的事实，不能因为"看起来像"就给评级。查不到足够信息时，标注"数据不足，暂无法评级"。

### 第三步：横向对比输出
如果用户要求对比多家公司，输出对比表格。

### 第四步：尽调后重新排名
完成所有公司的尽调后，**必须基于尽调事实对原岗位池排名进行修正**，产出尽调后排名。

**重新排名规则：**
- 原岗位池得分（job-recommender 第五步的加权总分）作为"岗位匹配基准分"
- 尽调风险等级作为重大调整因子：
  - 🟢 低风险：不做负向调整
  - 🟡 中风险：在原得分基础上 **-1 分**
  - 🔴 高风险：**直接移出推荐序列**，不参与排名，仅在最末"已排除"段列出并说明原因
- 尽调关注点（口碑负面/劳动纠纷/社保问题等）作为微调因子：视严重程度 **-0.3 至 -0.8 分**
- **调整后总分 = 岗位匹配基准分 + 风险等级调整 + 关注点微调**

**输出要求：**
1. 为每个尽调公司生成独立的尽调报告文件
2. 生成横向对比文件，内含尽调后重新排名
3. 两份文件均须落盘保存。

## 常见场景处理

### 场景1：小微企业（参保人数<30）
- 重点关注：薪资发放稳定性、社保是否按实际基数缴纳、项目回款风险
- 搜索："[公司名] 拖欠工资"、"[公司名] 劳动仲裁"
- 提示：小微企业抗风险能力弱，项目制公司尤其要注意回款节奏

### 场景2：政企/国企外包类公司
- 重点关注：是否是正式员工还是外包驻场、社保公积金缴纳标准、项目周期稳定性
- 搜索："[公司名] 中标"、"[公司名] 国家电网"（或对应行业关键词）
- 提示：高度依赖单一央企客户的公司，客户预算收缩时风险大

### 场景3：成立1-2年的新公司
- 重点关注：股东背景、融资情况、团队来源
- 搜索："[公司名] 融资"、"[创始人名] 背景"
- 提示：新公司数据少，风险不确定性高，建议把薪资/试用期条款谈清楚

### 场景4：搜到大量负面信息
- 不要直接说"这家公司是坑"
- 客观陈述："根据XX平台X条评价，集中反馈的问题是XXX"
- 标注评价的时间分布（是最近的还是几年前的老黄历）

## 禁止行为清单
1. ❌ 禁止编造参保人数、注册资本、案件数量等任何数字
2. ❌ 禁止用"据了解"、"一般来说"这种没有来源的表述
3. ❌ 禁止把"未查到"等同于"没有"
4. ❌ 禁止直接下"这家公司不靠谱"的结论，要给出事实+推演
5. ❌ 禁止预测公司未来会不会倒闭，只说"基于当前数据，存在XX风险"

## 数据源优先级
1. 企查查/天眼查/国家企业信用信息公示系统（最权威）
2. 中国执行信息公开网、裁判文书网（司法数据权威）
3. 信用中国（行政处罚、欠税）
4. 公司官网、官方公众号（业务模式）
5. 脉脉、职友集、知乎、小红书（员工口碑，注意区分真假）
6. 招投标网站（项目活跃度）
