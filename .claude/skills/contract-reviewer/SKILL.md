# 劳动合同审核（对照知识库逐条检查）

## 这个 skill 干什么

用户拿到劳动合同或 offer 准备签字时，把合同内容贴进来，我对照 `knowledge-base/毕业常识完整版.md` 第四部分（第二十一至三十节）逐条检查，输出：
- 风险等级
- 有问题的条款清单（引用知识库对应章节）
- 修改建议和话术
- 签字前自检清单

**知识库依据**：所有判断都来自《毕业常识完整版》，不凭感觉。

- 社保公积金条款 → `knowledge-base/五险一金与个税实操手册.md`：第二步 B 薪资条款与第0步（前置）核"薪资结构拆分"时，用它检查合同/offer 里的社保与公积金条款——缴费基数按实际工资还是最低基数、缴存比例多少、从哪个月开始缴、有没有"自愿放弃社保"表述（红旗清单），并据此算出对到手的实际影响。
- 条款定位到章节 → `knowledge-base/法律知识快速索引.md`：第四/五步要写"这条对应《毕业常识完整版》第 X 部分第 X 节"时，先用索引表按场景（合同陷阱、社保、试用期、违约金）定位章节号，再去完整版看详情；报告里的法律依据必须带章节号，不能只写"根据劳动法"。

---

## 执行流程

### 第0步（前置）：确认求职身份（大学生 / 社会人员）

在开始逐条审核前，**先向用户确认求职身份**，不同身份首要审核的条款不同：

**🎓 大学生 / 应届生（校招、实习通道）**
- **本 skill 的身份差异（先核这几项）**：
  - **先分清实习协议 vs 劳动合同**：在校生实习不建立劳动关系、公司**无强制社保义务**，别用劳动合同标准误判（也别被"实习协议"包装成正式offer）
  - **三方协议违约金条款**（违约金金额、哪一方违约才生效、是否与劳动合同冲突）
  - **试用期期限与工资下限**（合同期对应法定上限、≥转正80% 且 ≥ 当地最低工资）

**💼 社会人员 / 在职跳槽（社招通道）**
- **本 skill 的身份差异（先核这几项）**：
  - **竞业限制范围与经济补偿是否约定**（无补偿约定=离职后白限制；范围是否具体竞品、期限 ≤2年）
  - **薪资结构拆分**（base / 绩效 / 补贴的比例——直接决定加班费与经济补偿金基数，低 base 高补贴 = 隐性风险）
  - **保密条款**边界（是否把通用技能也列为机密）
  - **期权兑现条款**（行权价、成熟期、离职后处置，口头不算数）
  - **是否需要前单位离职证明**（背调连续性与双重劳动关系风险）

**判定规则**：优先直接问用户；用户自述优先于简历/合同文本的任何推断，简历只作证据；无法确定时默认"🎓 大学生"分支，并在报告顶部标注「身份待确认」。确认后，下方逐条检查按对应身份侧重排序。

---

### 第一步：收集输入

让用户提供：
1. 劳动合同全文（或关键条款）
2. 书面 offer（如有）
3. 公司名称和岗位（用于判断是否有行业特殊性）
4. 求职身份（🎓 大学生/应届生 还是 💼 社会人员，第0步（前置）已确认）

如果用户只提供了部分条款，就只审核提供的部分，并提示"未提供的条款无法审核"。

---

### 第二步：逐条对照知识库检查

按以下维度逐条检查，每条都引用知识库的对应章节：

**A. 主体信息（知识库第三十节自检清单）**
- 甲方公司全称、统一社会信用代码是否与面试公司一致
- 是否是劳务派遣/外包（合同签约方 ≠ 实际工作单位）

**B. 薪资条款（知识库第二十一节）**
- 基本工资是否低于南京最低工资 2660元
- 绩效占比是否过高、考核标准是否空白
- 年终奖/13薪是否写进合同或盖章附件
- 补贴是否约定为"可随时取消"

**C. 试用期条款（知识库第二十二节）**
- 试用期时长是否超过法定上限（合同3年以上≤6个月）
- 试用期工资是否 ≥ 转正80% 且 ≥ 2660元
- 录用条件是否客观可量化（不能是"主观评价"）
- 是否单独签了"试用期合同"（违法）

**D. 岗位与工作地点（知识库第二十三节）**
- 岗位名称是否具体
- 工作地点是否写死（不能只写"南京市"）
- 是否有无条件调岗条款（应改为"双方协商一致"）

**E. 工时与加班（知识库第二十四节）**
- 是否写了"不定时工作制无加班费"——要求出示人社局审批文件
- 是否有"自愿放弃加班费"条款（无效但增加举证难度）

**F. 违约金与服务期（知识库第二十五节）**
- 是否只有"外部专项付费培训"和"竞业限制"两种违约金
- 内部培训、入职培训约定的违约金 → 无效

**G. 竞业限制（知识库第二十六节）**
- 是否写明竞业补偿金金额和发放时间
- 范围是否是具体竞品（不能是"所有AI公司"）
- 期限是否 ≤2年
- 普通开发/测试岗可以拒绝签

**H. 离职条款（知识库第二十七节）**
- 是否有"离职须经甲方审批"（无效）
- 是否有"发奖前离职奖金清零"（在职期间劳动所得不能清零）
- 是否扣押证件/押金/培训费（违法）

**I. 知识产权（知识库第二十八节）**
- 是否把业余时间个人作品也归公司（应加排除条款）

**J. 其他隐形坑（知识库第二十九节）**
- 空白合同（绝对不能签）
- 合同效力高于offer条款（应写明附件同等效力）
- 只给一份合同（必须双方各执一份）

### 第三步：输出审核报告

```markdown
# 劳动合同审核报告
**审核时间：[日期]**
**公司：[公司名]**
**岗位：[岗位名]**

## 风险等级：🔴高风险 / 🟡中风险 / 🟢低风险

## 一、问题条款清单
| 序号 | 条款位置 | 问题描述 | 知识库依据 | 风险等级 | 修改建议 |
|-----|---------|---------|-----------|---------|---------|
| 1 | 第X条 | [具体问题] | 第二十一节陷阱1 | 🔴 | [怎么改] |

## 二、必须修改的条款（不改不能签）
1. [条款] → [原因] → [改法]

## 三、可以协商的条款
1. [条款] → [建议]

## 四、没有问题的条款
- [已检查通过的条款]

## 五、签字前自检清单
- [ ] 甲方全称与面试公司一致
- [ ] 薪资结构清晰
- [ ] 试用期合法
- [ ] ...（引用知识库第三十节完整清单）

## 六、与HR沟通话术
### 针对[问题条款]
> "我看了合同第X条，想确认一下……能不能改成……"

## 七、最终建议
**建议：可以签 / 修改后签 / 不建议签**
**理由：**
1. [理由1]
2. [理由2]
```

## 常见问题快速判断

| 用户问 | 答案（引用知识库） |
|-------|------------------|
| "合同只写基本工资2280，口头说8K" | 🔴 高危。要求薪酬确认单写明固定工资和保底绩效，写进盖章附件（第二十一节） |
| "试用期6个月打8折" | 合同3年以上才合法，且工资≥2660。要求缩短到3个月或提高试用期工资（第二十二节） |
| "公司说不定时工作制没加班费" | 要求出示人社局审批文件，没有审批这条无效（第二十四节） |
| "让我签竞业协议但没说补偿金" | 不写补偿金的竞业无效，普通开发岗可以直接拒签（第二十六节） |
| "离职要赔培训费" | 内部培训不构成违约金，只有外部付费培训才行（第二十五节） |
| "合同说附件效力低于合同" | 要求加上"附件与本合同具有同等法律效力"（第二十九节） |

## 禁止行为

1. ❌ 禁止凭感觉判断，每条问题必须引用知识库对应章节
2. ❌ 禁止说"这个条款一般没问题"，必须说"根据知识库第X节，这个条款的风险是……"
3. ❌ 禁止替用户做最终决定，只给风险评估和建议
4. ❌ 禁止编造法律条文，所有法律依据来自知识库
5. ❌ 禁止让用户把合同原件整份交给 AI：合同同时含你的身份信息与用人单位的商业信息，提交前先抹掉姓名、证件号、公司全称（替换为 张三／XX 公司），只贴需要判断的条款
