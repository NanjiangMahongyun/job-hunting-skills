# 求职技能包 — 使用索引

> 最后更新：2026-10-23 · 版本 v1.0（首次公开基线）  
> 本页是**详版索引**。GitHub 首页渲染的是根目录 `README.md`（薄版：定位 + 30 秒上手 + 按处境找入口），两页定位不重叠，不要互相替换。  
> 适用对象：大学生（校招/实习）+ 社会人员（社招/跳槽），软件开发/AI 方向（可替换为任意方向）  
> 结构：**knowledge-base（判断依据）+ `.claude/skills/<name>/SKILL.md`（按目标拆分的处理工具，标准 skill 结构）**

## 〇、这个仓库的立场（先读这个）

一个普通求职者整理的求职方法库。目的是解决信息不对称——**不被压价、不被坑、依法拿到自己应得的东西，也不去占别人便宜**。

| 你需要注意的 | 本仓库的做法 |
|---|---|
| 是否针对某家公司 | ❌ 不针对任何真实企业或个人。所有示例均为虚构（XX 公司、张三），不含任何单位内幕、未公开资料或他人个人信息 |
| 是否教人造假 | ❌ 不教虚报薪资、伪造 offer/离职证明、隐瞒法定义务、伪造或诱导取证。只区分"真实前提下的表述方式"与"造假"，界线写在《职场小技巧与人情世故》《离职与背调合规手册》里 |
| 判据是什么 | 一条做法如果只有在你隐瞒真相时才有效，就不会出现在这个仓库里；换句话——**当着对方的面把这条做法说出来，你还愿不愿意承认** |
| 会不会教人取证越界 | ❌ 建议"留证据"的地方**同段写明合法边界**：只录你本人参与的对话，不窃听他人、不诱导陈述、不剪辑，不伪造不销毁证据。采信尺度各地有差异，一律写"以受理机关认定为准"，不把某地做法写成全国保证 |
| 是不是法律意见 | ⚠️ **不构成法律意见**。内容用于理解处境、准备问题清单；具体争议以官方答复（12333 人社 / 12348 法律援助 / 12366 税务 / 12329 公积金）或执业律师意见为准 |
| 数字与政策会不会过期 | ⚠️ 会。所有政策数字标注"机构 + 日期 + URL"，核实不到的一律写「未查到」而不是留一个看起来精确的旧数字；司法解释以**现行文本**为准（已废止的解释不再引用），引用前请复核一次 |
| 内容失实怎么办 | 开 issue 说明依据，核实后一律更正或删除。**不争论、不拖延**——本仓库不掌握任何需要维护的立场，只有需要更正的错误 |
| 发布前的合规自查 | 见 `knowledge-base/公开发布与免责合规手册.md`，以及 skill-upgrade-maintainer 的「第六步附：发布前叠甲体检」①—⑩——隐私、名誉权与商誉、商业秘密、个人信息（**含 git 提交携带的作者名与邮箱**，它不在文件里、grep 查不到，push 后永久公开）、取证边界、开源许可、免责与更正机制逐条过，**任一项未过不 push** |

## 第0步（所有 skill 通用）：先确认你是 🎓 还是 💼

**每个 skill 的执行流程第 0 步都是确认求职身份**——它决定后续查什么、怎么定价、哪些条款对你有利：

| 维度     | 🎓 大学生 / 应届生（校招、实习）                        | 💼 社会人员（社招、跳槽）                     |
| ------ | --------------------------------------------- | ----------------------------------- |
| 法律关系   | 实习阶段不建立劳动关系，社保非强制                          | 劳动合同 + 五险一金强制                       |
| 定价锚    | 行业起薪 + 城市应届补贴（生活/租房/落户）                     | 当前薪资流水 + 期望涨幅 15–30%                |
| 尽调重点   | 会不会坑学生：培养体系、签约主体是否外包、校招毁约记录                | 权益保不保得住：社保基数、竞业滥用、背调方式、近一年裁员        |
| 合同重点   | 实习协议 vs 劳动合同、三方协议违约金、试用期期限                  | 竞业限制与补偿、薪资拆分对加班费/补偿金基数的影响、期权条款      |
| 离职重点   | 转正条件是否书面约定                                 | 交接期、离职证明、社保衔接、空窗期与跳槽理由口径             |

**判定规则（全库统一）**：优先直接问用户 → **用户自述优先于简历或历史记录的任何推断**（简历只记录"过去做了什么"，常滞后于当下方向）→ 无法确定时默认 🎓 大学生并在报告顶部标注「身份待确认」。身份发生变化（毕业、入职、转正、离职）时，让 memory-manager 把变更写入 profile 与 current-state 并记录日期。

## 使用前建议：知识库怎么读（可以只读、不跑 skill）

## Skills（按目标拆分的处理工具）

每个 skill 都是：**输入数据 → 查找/对照知识库 → 输出建议**。目录为 `.claude/skills/<name>/SKILL.md`，`name` 即下方标题。

### job-recommender（岗位推荐）

- **目标**：按条件找岗位，默认 30 个岗位（保底可超；用户可指定“最多30个”或“30家公司”口径）
- **输入**：**先确认求职身份（大学生/社会人员）** + 岗位方向、地区、薪资预期、其他偏好（双休/外包/公司规模）；社招含工作年限/在职离职/期望涨幅/背调
- **处理**：多平台多关键词搜索 → 逐条记录发布时间、在招状态、招聘链接 → 实际打开链接核验（✅直接打开/🔐需登录/⚠️状态不明/❌失效）→ 达标/备选分层 → 公司风险初筛 → 打分排序；不足 30 补搜 2-3 次
- **输出**：岗位池报告（含投递链接核验表、公司去重表）；过期/关闭/失效岗位不计入 30；落盘 `memory/03-job-pool/[地区]-[方向].md`
- **何时用**：刚开始投简历、想知道有哪些机会时
- **下一步**：报告末尾让用户选尽调范围（几家/全部），交给 company-due-diligence

### company-due-diligence（公司尽调）

- **目标**：搞清楚这家公司靠不靠谱，并在全部查完后给出可依次投递的总排名
- **输入**：公司名称或岗位池范围（**第0步先确认求职身份 → 再确认数据获取方式 → 再确认范围：指定几家/全部**）
- **处理**：**第0步确认身份**（🎓 重点查是否坑学生：培养体系、签约主体是否外包/第三方人力、拖欠实习报酬、校招毁约；💼 重点查权益：社保实缴人数与基数、竞业是否滥用、第三方背调、劳动仲裁与欠税、近一年裁员）→ **再确认是否有企查查等付费API（有则付费调用，无则默认免费版）** → 读岗位池去重公司并让用户选范围 → 联网查工商/司法/口碑 + 逐条复核该公司全部岗位链接与在招状态 → 逐家出独立报告 → 更新留存索引 → 本批全部完成后横向对比 + 尽调后总排名
- **输出**：公司风险评级（🔴🟡🟢）+ 岗位级风险（外包/驻场/异地等）+ 风险点 + 面试必问 + 全部岗位投递链接；横向对比/总排名/投递作战清单；单公司报告落 `memory/04-due-diligence/companies/`，排名落 `memory/04-due-diligence/rankings/[方向]/`，两份索引分别留存
- **何时用**：拿到面试邀请后、拿到offer后；或岗位池出来后准备按排名投递时

### job-negotiation-strategist（谈判筹码分析）

- **目标**：找出你的优势和公司的软肋，变成谈判筹码
- **输入**：你的简历 + 目标公司尽调结果
- **处理**：**先确认求职身份（大学生/社会人员）** + 确认求职方向与自我定位（用户自述优先，不只看简历） → 提取简历优势 → **按确认方向做行业背景分析（industry-background-analyzer）** → **确定目标公司（先问是否已有心仪公司；没有则由 AI 按简历+行业趋势全网推荐，即 job-recommender）** → 提取公司劣势 → 匹配"我的优势解决公司什么痛"
- **输出**：筹码清单（硬/软/补偿）+ 定制话术 + 让步策略（行业薪资用于目标价定价）；**社招走跳槽加薪逻辑（涨幅15-30%）、薪资流水、offer比较、竞业**
- **何时用**：拿到口头offer准备谈薪；或没目标公司、想先让AI按方向+趋势推荐合适公司时

### salary-negotiation（谈薪执行）

- **目标**：具体怎么谈、怎么应对HR压价
- **输入**：offer内容 + 目标薪资（**第0步先确认求职身份**）
- **处理**：**第0步确认身份**（🎓 定价锚=行业起薪+城市应届补贴，薪酬包看培养与户口；💼 定价锚=当前薪资流水+涨幅15-30%，薪酬包看职级、签字费、期权、绩效保底）→ 拆解薪酬包 → 市场价对标 → 三档定价（底线/目标/要价）→ 按公司风险等级定策略
- **输出**：谈判方案 + 分场景话术 + offer校验清单
- **何时用**：正式和HR谈薪时

### contract-reviewer（合同审核）

- **目标**：签字前最后一道防线，逐条查坑
- **输入**：劳动合同/offer条款（**第0步先确认求职身份**）
- **处理**：**第0步确认身份**（🎓 先分清实习协议 vs 劳动合同、三方协议违约金、试用期期限与工资下限；💼 先核竞业限制范围与补偿是否约定、薪资拆分、保密与期权条款、是否需前单位离职证明）→ 对照知识库第四部分（第二十一至三十节）逐条检查
- **输出**：风险等级 + 问题条款清单 + 修改建议 + 自检清单
- **何时用**：拿到合同准备签字时

### severance-calculator（补偿金与维权）

- **目标**：被辞退/想走时算清钱、走好流程
- **输入**：入职日期、月薪、离职原因
- **处理**：**先确认求职身份** → 计算N/N+1/2N → 判断公司操作合法性 → 对照知识库第六、七部分；**社招含竞业限制、社保断缴补缴、背调、裁员场景**
- **输出**：补偿金额 + 应对步骤 + 证据清单 + 仲裁流程
- **何时用**：被辞退、被劝退、被迫离职时

### industry-background-analyzer（行业背景分析）

- **目标**：摸清目标行业的最新形势，决定值不值得进
- **输入**：**第0步确认求职身份** + **确认求职方向与自我定位** + 你的简历 或 指定行业/岗位
- **处理**：按身份定检索口径（🎓 只看校招供给、对口专业报名/就业数据、起薪区间、头部公司校招规模；💼 只看社招岗位量与跳槽涨幅、行业裁员/扩编动态、目标职级供需）→ 联网搜行业动态/发展趋势/就业数据/政策/头部公司
- **输出**：行业背景报告（现状、薪资、竞争、供需、政策、对你的建议）
- **何时用**：选方向时、想知道某个行业有没有前途时

### jd-analysis-and-resume-tailoring（JD分析与简历定制）

- **目标**：分析岗位要求，针对具体JD定制简历
- **输入**：岗位描述(JD) + 你的简历
- **处理**：**先确认求职身份（大学生/社会人员）** → 提取必备条件/加分项/岗位解决的问题/红旗信号 → 按5原则定制简历；**社招含空窗期/频繁跳槽/跳槽理由处理**
- **输出**：JD分析报告 + 定制后的简历 + 修改说明
- **何时用**：投简历前、针对特定公司优化简历时
- **借鉴来源**：[github/awesome-copilot → skills/technical-job-search](https://github.com/github/awesome-copilot/blob/main/skills/technical-job-search/SKILL.md)（MIT）。JD 拆解结构与简历定制 5 原则改写自该框架；中国校招/社招场景部分（三方协议、社保公积金、外包签约主体、空窗期）为本仓库原创

### onjob-management（入职后在岗管理）

- **目标**：把"入职后"这段管起来——在岗策略 + 公司/岗位风险监测
- **输入**：**第0步确认求职身份** + **确认当前处境**（公司/行业/规模/经营状况、岗位、上级风格、入职时间、是否在试用期、核心诉求）
- **处理**：试用期 30/60/90 天目标 → 融入与 visibility（对齐预期、找关键人、主动暴露风险）→ 绩效博弈 → 公司恶化信号 + 岗位被架空信号预警
- **输出**：在岗管理报告（在岗策略 + 风险监测表 + 是否触发跳槽评估的结论）
- **何时用**：入职前后、试用期、感觉"不对劲"想确认时
- **联动**：软技巧引用 职场小技巧与人情世故.md；监测到 ≥2 个预警 → job-switch-decision
- **同类现状**：github 成熟求职 skill 不覆盖在职管理，本 skill 为自建方法论补位

### job-switch-decision（主动离职与跳槽决策）

- **目标**：判断"该不该走、什么时候走、怎么走"，安全落到新工作
- **输入**：**第0步确认求职身份** + **确认当前处境**（公司/岗位/在职时长/职级/薪资/为什么想走/想跳到哪）
- **处理**：该走的信号 vs 可再等 → 跳槽窗口（金三银四/金九银十、拿年终或背书后再走）→ 在职骑驴找马八步（简历→找→面试→定offer→提离→交接→离职证明→社保衔接→背调→竞业核实）→ 跳槽理由口径统一
- **输出**：主动跳槽决策报告（建议留下/骑驴找马/尽快走 + 时机 + 步骤 + 注意事项）
- **何时用**：动了"想走"的念头、拿到外部机会、在岗风险信号累积时
- **边界**：被辞退/被迫离职的补偿与仲裁 → severance-calculator；交接/竞业/社保/背调细节 → 离职与背调合规手册.md
- **同类现状**：github 无"求职者主动跳槽决策"的现成独立 skill，本 skill 为自建方法论补位

### memory-manager（记忆库管理）

- **目标**：跨会话持久化你的信息，下次回来直接接上
- **输入**：用户资料、分析结果、职业状态变化
- **处理**：**读取前先校验「求职身份」字段是否在有效期**（毕业/入职/转正/离职都会改变身份，缺失或存疑先问用户）→ 读取/更新 profile、career-timeline、current-state，归档分析结果；身份变更同时写入 profile 与 current-state 并记录变更日期
- **输出**：更新后的记忆文件 + 变更摘要
- **何时用**：每次对话自动读取；提供新资料、完成分析、职业状态变化时更新
- **注意**：记忆库属个人隐私，公开版不含 `memory/`，由各人自行维护在本地

### skill-upgrade-maintainer（技能包升级更新）

- **目标**：对整套技能包做"体检 + 升级"，保证持续贴合求职者的处境
- **输入**：当前求职阶段/方向/身份 + 技能包现状
- **处理**：加载全景+结构自检 → 审视意图 → 体检知识库（时效/完整/缺口）→ 查漏补缺 → 优化 skill 提示词 → 增加实用步骤/新 skill → 同步 README／索引／流程图
- **输出**：技能包升级报告（vX→vY）+ 更新的文件
- **何时用**：定期（每月/季度）、求职阶段或方向变化、政策调整、复盘发现问题时

## 标准使用流程

```
第0步（每次必做）
  └─ 确认身份：🎓 大学生/应届（校招、实习） or 💼 社会人员（社招、跳槽）→ 后续每个 skill 都按身份走分支

  └─ industry-background-analyzer：行业背景分析 → 摸清行业形势，决定要不要进

投简历前
  └─ 知识库：毕业常识第一部分（应届生身份、三方、补贴）
  └─ 知识库：AI辅助求职实操教程（优化简历，含简历定制5原则）

面试前
  └─ company-due-diligence：公司尽调 → 逐家独立报告 + 留存索引 → 全部完成后横向对比/总排名/投递清单
  └─ 知识库：面试高频问题与作答框架 → 项目深挖、STAR 事例、反问清单

面试后 / 拿到口头offer
  └─ job-negotiation-strategist：谈判筹码分析 → 你的优势 + 公司劣势 = 筹码
  └─ salary-negotiation：谈薪执行 → 具体话术和策略

拿到书面offer/合同
  └─ contract-reviewer：合同审核 → 逐条查坑，对照知识库第四部分

入职后
  └─ onjob-management：在岗管理 → 试用期30/60/90天目标 + 融入留痕 + 公司/岗位风险监测
  └─ 知识库：毕业常识第五部分（五险一金、加班费、假期）
  └─ 知识库：五险一金与个税实操手册（首月就核对缴费基数，别等离职才发现）
  └─ 知识库：职场小技巧与人情世故（留痕、汇报、拒绝）

感觉不对劲 / 想走
  └─ onjob-management 监测到 ≥2 个预警 → job-switch-decision：该不该走、时机、怎么走

被辞退/被迫离职
  └─ severance-calculator：补偿金与维权 → 算清钱，留好证据，走仲裁

技能包本身维护
  └─ skill-upgrade-maintainer：定期体检 + 查漏补缺 + 同步对外文档
```
